# 演奏表达换谱与内置处理检查 · 0.149.0

## 查到的问题

旧页面换谱时清空对应和候选，留下原MIDI和表达项目路径。先用独立双谱表例子重现；换到新谱后，界面仍带着上一份演奏。

当前按打开的乐谱分别保留材料、对应、比例、人工修改和项目路径。乐谱关闭时结束这份内存资料，显式保存的表达项目用于重开恢复。原生保存对象与读取编号分别处理，普通换标签页可以沿用已经算好的结果。

还查到内置页的处理代码较早。现已同步独立页面已有的对应、速度和撤销修正；内置界面的布局段保持原样。新增一致性检查同时核对两种入口的控制代码与五份公共规则。


连续检查还复现了一处退出：采用力度、关闭真实演奏谱后，再显示下一份谱时，恢复力度数量会扫描全局记录，访问临时装饰音已经销毁的父和弦。调试调用落在VelocityBackup::notes与Chord::segment，现改为遍历当前谱上实际存在的音再读取记录。临时装饰音、复制谱、撤销与重做单独检查。

## F-C1-B2-A：实际操作

使用独立钢琴谱及ASAP的巴赫BWV846演奏材料：

1. 导入MIDI，保存表达项目，再把采用比例改为42%，选择一个对应项。
2. 切到另一份谱，导入另一份MIDI，采用比例设77%。
3. 两份谱来回切换三轮，核对材料、对应、比例、选中项、范围、项目路径及逐音候选。收起并打开编辑器后继续检查。
4. 检查两份谱的内容状态和撤销位置，切换保持原值。
5. 修改另一份未显示的谱，再回到它，更新对应后继续使用。
6. 读取表达项目时立即切谱，返回后完成读取；关闭乐谱、重开MSCZ，再显式载入表达项目。
7. 恢复后选择一个对应音，实际采用力度并撤销；核对写入值和保存方式。
8. 保留已完成的速度预览；同一范围切回时沿用结果，改选另一范围后重新计算，谱内容和撤销位置保持。
7. 恢复后选择一个对应音，实际采用力度并撤销；核对写入值和保存方式。
8. 保留已完成的速度预览；同一范围切回时沿用结果，改选另一范围后重新计算，谱内容和撤销位置保持。

原始乐谱保持相同校验值。真实材料的547组人工对应全部匹配，可直接使用的547组也全部正确。数据与许可保留在本地独立目录，来源为[ASAP资料](https://github.com/CPJKU/asap-dataset)。
