# 按实际播放检查低音排列

对应0.122.0。程序安装状态见[进度记录](REWORK_PROGRESS.md)。

## 从哪里开始

1. 打开乐谱，选择需要检查的钢琴谱段。
2. 打开“插件 → Arrangement Check”。面板上方显示检查的小节范围。
3. 点“更新结果”。先显示“准备实际演奏”和进度，再显示读取的音符与踏板数量，最后显示“已更新”。
4. 在“和声”类中选一条“低音排列可能较浑浊”，下方会列出具体音、共同持续时间、起音力度和踏板来源。
5. 点“定位相关音”，从该处播放，听一听两个低音同时存在时的效果。

范围下拉可以切回“钢琴全谱”或保留这次范围。编辑其它音、点空白处，结果继续留在列表中。

## 手调音长后怎样检查

例如，C2和C♯2写在同一个位置。演奏编辑器把C2改为很短，把C♯2的起音向后移：

- C2已松开，C♯2才开始，两音没有共同发声时，这一对的提示会消失。
- 踏板在C2松开前已经踩下，C2继续留声，与后来的C♯2重叠时，提示会保留。
- 踏板在C2松开后才踩下，已经结束的C2保持结束。

修改后点“更新结果”；开启自动更新时，停播后会自行更新保留的范围。同音加倍、重复起音、关闭播放的音和反复遍次也采用当前演奏资料。

## 怎样读持续时间

下图中，两个音因踏板共同保持约751毫秒，起音力度分别为80和80。

![实际起音、松键与踏板下的提示](images/review-20261025/arrangement-actual-panel-122-final.png)

“实际共同持续”从两音都已开始时计算，到其中一音松键且踏板结束保持时为止。谱内速度变化和起音微调会改变这个时间。仍然按住的长音在抬踏板后继续保持按键时长。

## 两种踏板方式

在演奏编辑器选择“延音踏板”，打开“踏板播放…”，可以使用“SF2原有方式”或“钢琴换踏板”。编配检查读取这次真正采用的踩下、抬起位置。

例如，一个短音在24毫秒左右已经松开，而踏板到80毫秒才踩下，它会在踩踏板前结束。改踏板方式后再次更新，就能看到这处共同持续是否还存在。完整设置见[钢琴踏板操作](PEDAL_106_GUIDE.md)。

## 逐处查看、保存与撤销

相同排列多次出现时，列表合成一行，保留“上一处／下一处”。反复演奏中的提示同时标明遍次。“忽略此处”只处理当前位置，恢复入口在“更多 → 恢复已忽略的提示”。

音符、演奏音长、起音和踏板修改跟随乐谱保存，可用Ctrl+Z撤销。保存后重新打开，再点“更新结果”，会按保存的演奏设置重新检查。面板设置和忽略列表继续由工具保存。
