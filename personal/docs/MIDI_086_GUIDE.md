# 比较和调整 MIDI 的松手位置

文件 → 导出，格式选“MIDI”，勾选“人性化裁剪：保守踏板模式”，再点“查看对比…”。

这个工具处理导出文件中的按键长度。比如低音写满一小节，踏板也保持着，手指可以提前松开去弹下一组音。谱上的音符和时值仍按原来的写法保存。

只希望处理影响后面弹奏的旧音时，在“范围与松手…”关闭“其余音加入自然松手”。具体例子见[按需要安排松手](MIDI_RELEASE_132_GUIDE.md)。

## 第一次使用

1. 顶部选择要导出的乐谱和钢琴部分。“范围与松手…”设置小节、最短按键时间和自然变化；“谱表与保护…”选择参与处理、需要保留的声部。
2. 点“匹配内容”查看整段。默认“只看有音的行”，低音和高音会排列在相邻的音高行；左侧写出实际音名，跳过的音高用折线提示。取消勾选后按完整音域查看。
3. 点一个音，查看下面的音名、原时长、新时长及原因。下方踏板轨显示这个音所在通道的踏板范围。
4. 点“听原长度”或“听新长度”。正在听的按钮保持选中；切换时从当前拍位继续。点“暂停”或在图中按空格暂停、继续。
5. 拖动实心条的右端调整松手点。淡色范围是按当前踏板、最短音长和保护条件允许调整的位置。按 Esc 取消这一次拖动，Ctrl+Z 撤销完成的调整，Ctrl+Y 重做。
6. 勾选“导出采用新长度”，点“返回导出”，继续选择文件名并保存。勾选“同时导出处理前版本”，还会保存一份原长度 MIDI，便于在熟悉的播放器里比较。

## 读图和寻找音符

- 细虚线框是原按键长度，强调色实心条是新长度；保持原样的音淡化显示。图例就在图表上方。
- “叠加”在同一音高行比较两种长度；“上下分列”分开看原、新音符。
- “全部／已缩短／保留”用于筛选，左边的“图上显示”可以只看某个谱表。这些选项用于看图，试听仍播放这份乐谱。
- 时间缩放滑块可以连续放大、缩小。Ctrl+滚轮围绕鼠标缩放时间，Shift+滚轮调整音高行，鼠标中键拖动画面。
- 拖图表与音符列表之间的分隔条，调整两边高度。“音符列表”按钮可以收起、再打开列表。
- 点时间尺或图中空白处，选择另一个试听起点。停止时点选音符，也会把试听起点放到这个音。
- 播放中点选其它音可以看详情，声音继续从当前拍位播放。

## 手动保留与恢复

“排除这个音”让选中音保留原长度；按钮随后变成“恢复这个音的处理”。这一步也能撤销。右键音符还可以选择“保持原长度”或“恢复自动松手”。

拖动只修改这个音在本次导出中的这一次出现。包含反复的乐谱中，其它出现仍单独处理。重新打开“查看对比…”可以继续这一轮导出的手动调整；开始新一轮导出会重新计算。

## 在大窗口里调整

点“在演奏编辑器调整…”，打开“演奏编辑器 · 导出音长”。图表、筛选、列表、试听与撤销使用同一份结果，可以继续调整并最大化查看。点“完成调整，返回导出”，演奏编辑器恢复此前的位置和内容。

如果试听按钮提示声音设备未启用，可以到软件设置启用声音输出，或先导出原、新两份 MIDI 比较。导出文件采用当前图中的长度和参数。
