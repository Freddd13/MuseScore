# C4-B与C4-C1：必要松手、成组变化和踏板预览

2026-10-28。0.132.0已编译安装。

## 先复现的四处问题

1. MIDI中先松键再在同一刻重触的同音，已经能唯一配对，处理器仍将它们标为重叠并全部保留。
2. 一处不确定的分手使整组手位处理被跳过；确定的左手低音只有一般缩短，没有按后面的和弦安排必要松手。
3. 需要松开一个音时，候选只比较数量和跨度，没有比较损失的按键时长。谱例中可以松开即将结束的C3，却选了仍需持续的C4。
4. 对比窗口忽略“导出谱上原始踏板”。实测同一C2预览1999毫秒，导出441毫秒。

前三个新例子在修复前失败；独立的105组枚举旧例通过。随后单独确认踏板预览失败，记录均保留。

## 修改

- 区分真正重叠与唯一配对的相接同音；起音先于前音松键造成的歧义继续保留。
- 不确定分手本身保持原状，已确定的旧音继续参与必要松手。
- 共用手位模块按最少松键、最少提前时间、手型依次比较。同音多声部的持续时间按共同物理琴键处理；允许的指法匹配仍逐项核对。
- 增加“其余音加入自然松手”，默认延续原方式。关闭后保留其余音长，手动尾端仍可调整；设置的取消和保存一起检查。
- 对比读取当前选择的踏板方式，准备的MIDI数据与导出一致。
