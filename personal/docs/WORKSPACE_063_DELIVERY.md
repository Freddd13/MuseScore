# 0.63：连接 Codex 与分享开关

## 从哪里开始

打开乐谱，从“视图 → AI 连接”点击“配置 Codex”。重新打开 Codex 后新建对话，请它读取当前谱名、选区和音符。“检查连接”会检查实际通信，窗口中可选择正在运行的谱。

完整操作见[AI 连接与个人扩展开关](WORKSPACE_063_GUIDE.md)，软件内的“帮助 → 个人功能说明”也可打开说明。

## 本批完成的修改

- 程序管理本机连接，随包提供 `bin/tools/mcp/MuseScoreMCP.exe` 与 Python 运行文件。
- Codex 配置更新前保留备份，保留其它服务和个人设置。多窗口切换后，下一次操作随选择更新。
- 程序旁 `kumo.ini` 统一控制个人工具。升级保留原值；关闭时隐藏入口并停止个人服务，谱内资料继续保存。
- 和弦、原曲、表达的内置界面放入独立资源目录。安装包整理旧插件入口，公共组件与独立插件继续提供。
- 说明改为按任务阅读，旧连接步骤放入附录，补充真实窗口截图。
- UI 的字体、间距、状态、删除及恢复要求写入两仓库 AGENTS.md。
