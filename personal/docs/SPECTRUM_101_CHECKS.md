# 长录音浏览与连续写谱检查

对应0.101.0，接续B3手动扒谱。使用独立钢琴谱、三分钟测试音频及现有短录音，用户材料保持原样。

## 本次改动

在长录音末尾取音并写入后，下方仍显示“先在乐谱中选择音符或休止符”。当时输入光标已有效，第二次输入也能写入下一拍。旧画面与位置读取见`spectrum-101-continuous-pluginhost.txt`。

现在谱面选音、输入光标和写入完成都会更新目的位置。普通选音时读取所选音符或休止符，进入输入模式后读取输入光标；时值尚未选定时提示“输入时选择时值”。原有配色、显示方式和灵敏度继续使用个人设置。

## 完整操作

1. 打开三分钟WAV，进入扒谱的“整条录音 · 原曲时间”。
2. 用底部时间条到录音末尾，Ctrl滚轮放大；核对仍在约2分55秒的位置，并复用已有频谱块。
3. 点亮线，标注E4。在乐谱选择休止符、声部和四分时值，点击“输入乐谱”。
4. 核对实际音高、下一输入位置，再点一次输入，核对下一拍。
5. 在频谱按空格播放、再按空格暂停，保存并重新读取MSCZ；逐次撤销两次输入和一次标注。

## 长录音与缓存

WAV、MP3、FLAC均采用180秒、330Hz的独立测试信号。分别查看88—96秒，在90—94秒放大，再查看60—180秒；新建分析会话后核对磁盘缓存结果。

- 主亮线位置约E4，三种格式一致。
- 已有范围缩放新增分析块数为0。重新打开会话后，120秒范围的30块均从缓存读取，图像相同。
- 本机首次8秒范围等待约123—187毫秒，已有范围缩放约62毫秒，120秒范围约1.43—2.37秒。这些时间包含检查程序等待结果的时间。
- 测试将分析内存缓存设为8MiB，连续三格式后约6.8MiB；这是分析缓存用量。取消较长低音分析约92毫秒完成，随后换另一录音，最终图像属于新文件。

算法与格式检查20项通过，日志`spectrum-101-before.txt`。图像读取、声音过滤与已知频率用于核对软件结果；声卡上的真实音乐听感继续按B5／F检查。
