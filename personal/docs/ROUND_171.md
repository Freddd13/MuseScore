# 0.171：调完力度继续编辑，工具设置随谱保存

## 连着调整和选音

在谱面用 Ctrl 选择两个音，拖动力度手柄或用滚轮调力度，松开后直接选择下一个音。音头附近有另一个音的力度手柄时，点击音头仍按正常方式选音。演奏对比区松开鼠标后，可以接着操作谱面和其它面板。

这次调整了两处输入处理：音头优先于附近手柄；顶层窗口收到的鼠标事件继续交给 Qt 派发，编辑器在实际控件中处理拖动。右键框选沿用自己的按钮状态。

## 把当前工作留在谱里

1. 打开一份谱，选择编曲、DAW、雕版或后处理视图。
2. 摆好面板，调整区域高度、展开或收起需要的工具；选择编辑器中的谱表、声部和显示方式。
3. 在原曲或频谱中浏览到要继续的位置。演奏表达和节奏草稿可保留当前资料。
4. 按 Ctrl+S，或用“另存为”保存。
5. 换到另一份谱，可单独摆放。返回或重开时，各自恢复。

保存内容包括工作视图、停靠／浮动位置、最小化与展开状态、编辑器参数和筛选、数值范围、缩放及播放位置。频谱还保存配色、听辨选项、音域和时间视窗；原曲保留各音轨的位置和视窗。编配检查保留检查范围、角色校正与忽略项，并按当前乐谱更新。

新打开的旧谱沿用本机原有设置。音频／MIDI 设备、插件扫描位置和共用钢琴按当前电脑设置。原曲录音继续与谱文件一起搬移，详见[原曲参考](../USER_GUIDE.md)。

## 这次怎样复现和修复点击问题

检查使用独立谱例：第一小节上声部依次为 C5、E5、G5、C5，下面有持续低音。

1. 打开演奏编辑器，启用音旁手柄。
2. 用 Ctrl 多选两个音，拖动其中一个力度手柄，或在音头上滚轮调整。
3. 松键后立即点另一个音头，再操作编辑器的试听按钮。相邻手柄不能抢走音头点击。
4. 导入演奏 MIDI，显示拟采用力度；拖动强调色力度柱后松开，再操作谱面及其它面板。

旧的演奏对比处理会在顶层窗口截走松键消息。独立检查记录到了这一刻：鼠标已经松开，Qt 的按下目标仍指向参数区。新版让这条消息先完成正常派发，对比拖动只由自己的画布处理。音头与手柄重叠则优先选音。

检查还包含调力度后播放、停止、再选音，以及播放中保存。保存之后继续播放，写出的谱中同时保留已调力度和工具状态。

## 位置与草稿的检查

两份谱分别使用不同的高度、显示方式、频谱数值和播放器浮动状态，经过切换、保存和重开后分别恢复。节奏草稿中改过的力度也随谱恢复。浮动播放器与编辑器的尺寸分开记录，切谱前先收集原谱的缩放与视口。

## 操作检查

独立 Windows 测试窗口完成了：Ctrl 多选、真正修改两个音的力度、松键后选择下一音、演奏对比拖动，以及连续播放／停止后操作其它按钮。检查直接核对 Qt 和 Windows 的鼠标归属，并确认实际力度和选音。

两份独立谱分别设置了不同的编辑器高度、显示方式和频谱参数，经过切换、正常保存与重新打开，恢复各自的设置；音符内容保持一致。检查用的运行文件、设置和谱例都在独立目录。

独立程序在 `msvc.install_ui_0_171_x64/bin/MuseScore3Evo.exe`，可在下次使用时从这里打开。说明仍在“帮助 → 个人功能说明”。
