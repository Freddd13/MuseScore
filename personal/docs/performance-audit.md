# 个人功能性能审查

本轮审查以最新稳定个人版本为基线，只对可定位、能验证的 GUI 开销修改。音乐核心与音频回调不作推测性重写。

## 方法与范围

真实 Windows Qt 5.15.2、VS2019 v142 x64 Release；同机 10080／50064 音符，双谱表、四声部、长音和密集和弦。两区概览／局部、原生滚动、轴缩放、滚轮预览、首次快照、原生批选／提交分别计时。面板关闭／仅谱带／仅编辑器／两者同时开启各取 40 样本；P95 用实际耗时排序计算。源码内新增计时仅位于测试，不进入产品与音频回调。不同显示状态会改变原生视口尺寸，不能横向比较其全谱绘制时长。

## 本轮可避免的开销

| 路径 | 旧行为 | 修正 |
| --- | --- | --- |
| selectionChanged | 隐藏后仍遍历全部音符并调用 view.update | 记录待同步标记，重开时修复原生选择上下文；同上下文的可见选择不重复计算过滤 |
| setOverlaySystem | 每次换行扫描全谱音符和片段 | 二分进入小节 tick 区间，遍历当前谱行；真实音头位置仍按布局缓存 |
| updatePlayhead | 每次播放位置变化请求整个谱带重绘 | 同行只更新旧／新光标窄列；换行／布局／滚动继续完整修复损伤 |
| 谱面速度绘制 | 从全谱片段进入循环，越过其他谱行时可能继续扫描 | 复用当前谱行片段缓存；速度节点仅访问可见 tick 范围 |

## 其余个人功能的审查

- NoteVelocity／震音颤音包络：逐事件倍率在播放准备时生成，编辑器实际值范围从停播快照缓存；无包络快速返回。保留原整数舍入及播放中暂存边界。
- TempoExpression：没有可播放表达时快速返回，速度图在原生更新／撤销边界重建；既有编辑器曲线按时间区间查询与像素合并。没有把重建放到播放计时器。
- 自动时值、快速小音符、琶音、可调重音、自由圆滑线和手符号：成本位于编辑／渲染准备或原生排版；圆滑线节点最多 32 个。回归保留原生 Undo／保存／MIDI。
- 和声观察与临时预览：完整布局和几何避让仍有首次成本；播放使用已建时间索引和 active-marker 更新，隐藏表面停止插件计时器。未把以前版本的插件测量冒充本轮全部插件同时运行的帧耗时。
- 独立节拍器与音源：保持原实时路径和资源加载逻辑，本轮不修改音源／Driver；无法仅用 GUI 静音测试证明真实设备长时稳定。
- 并行 P0（0.25.1，efa4225bf）：合入稳定提交后复核 Tap、分页只读快照、规则工作线程及导出裁剪入口；只读分析不携带原生谱对象指针，裁剪处理事件副本。源文件 arrangementsnapshot.cpp／readonlyanalysisjob.cpp 已复核；该批原报告6000音符47页峰值1.015ms、真实插件GUI批次1–2ms。本轮已重新跑一致依赖的宿主测试，不将其声卡／所有插件同时运行的性能视为已测。

## 保留的成本与边界

首次全曲快照仍需要原生演奏事件、力度基准和索引。原生全组选择／Undo 提交仍有可测量成本；本轮不改变其音乐或撤销语义。测量仅说明本机此夹具，不承诺任意密度持续 60fps，不作为声卡硬实时结果。原版／MusicXML 往返、长时间真实编曲需按个人扩展原有限制验收。
