# 从完整演奏中取一段力度

选段与采用步骤始于个人版本0.95.0，适用于当前0.96.0 · Kumo branch / Freddd13。人工校正、对应撤销和导入失败后的恢复见[本次操作](EXPRESSION_096_GUIDE.md)。

## 先选谱段，再导入演奏

1. 在谱上选中要调整的几小节，打开“视图 → 演奏表达”。
2. 点“当前选区”，核对目标行写的小节、谱表和声部。要处理整首时点“全谱”。
3. 点“导入 MIDI”，选择完整演奏文件。软件会在录音中寻找这段，再列出对应音和新力度。琶音中的各音仍各自保留起音和力度。
4. 在“比较试听”点“谱中效果”或“拟采用效果”；“停止试听”结束播放。

同一段在演奏里出现多次时，“演奏片段”列出各次的起止秒数。选择本次要采用的时间位置，下面的对应和力度随之更新。这一选择与表达项目一起保存。

## 把力度用到谱里

新导入材料默认采用100%演奏力度，并逐音保存固定力度。例如列表写“80 → 66”，采用后这个音播放力度为66。要混合原来的力度，调整“采用演奏力度”的比例。

1. 只改一个音：点结果中的音，在“应用范围”选“选中音”，再点“使用力度 · 1音”。
2. 改一部分：在谱上选好范围，在“应用范围”选“当前选段”，核对按钮数量，再使用力度。
3. 改其余音：选择“全部已对应范围”，点“使用力度”。已经采用的音从“待使用”收起。
4. Ctrl+Z撤销这次采用，Ctrl+Shift+Z重做。Ctrl+S保存乐谱；重开MSCZ后，新力度及应用前的力度记录继续保留。

“继续跟随力度记号”将目标力度换算为相对增减。以后修改p、mf或渐强渐弱，这些音也随之变化。需要恢复时，打开“更多操作 → 恢复应用前力度”，选择音、选段或全曲。

## 对应需要调整时

在“对应结果”里切换“需核对”“漏弹”“多弹”。每行写出具体音名、拍位和原因；选一行，谱面与对应轨一起指向相关音。点“查看对应”展开编辑器中的对应区，可以改配对，再用“固定这一处对应”帮助附近的音重新接上。

快速反复音中漏弹几次，或短时间里多弹同音时，可能有几种合理对应。核对相关起音后继续采用；其它已经明确的音可以先使用。复杂装饰音选段的自动寻找还在继续调整，具体材料与当前结果见[本批检查](EXPRESSION_095_CHECKS.md)。

## 保存本次对应

Ctrl+S保存已经采用到谱里的演奏值。“更多操作 → 保存表达项目”保存原始MIDI、人工对应、所选演奏时间及设置。以后打开这份项目，可继续核对和采用剩余音。

录制操作及结果列表见[录完后继续操作](EXPRESSION_080_GUIDE.md)。窗口与区域高度见[区域摆放](LAYOUT_079_GUIDE.md)。
