# 和弦拼写、转位与连续换谱检查

对应0.109.0。独立谱例在本机Windows、正常大小的真实Qt谱窗中检查。官谱和用户乐谱保持原样。

## 复现和修复

- 修改前的即时计算把E、G♯、C判成E+，把E♭、G♭、B♭♭、C判成E♭dim7；级数还出现D♯配♭III、C♯调的F配III。保留原结果于`P2/out/probe_harmony_109.cjs`的检查资料。
- 加入谱上音名后，这些例子分别得到C+/E、Cdim7/E♭、D♯与♯II、F与♭IV。根音拼写、低音、转位和级数共同传给各显示位置。
- 第一次原生检查还复现连续关谱后第二份谱空白。旧谱释放后，新谱可能占用相同内存位置，面板曾误认仍是原谱。现在同时核对实际读取对象；关闭最后一谱、打开下一谱后直接检查结果，全程无需点分析。
- 导入分析替换根音时，一起更新当前根音的拼写，避免沿用刚才自动识别的音名。

## 具体谱例

人工核对表为`mtest/mscore/pluginhost/harmony_theory_109.json`，插件规则使用同一份表：

- 增三、减七各转位，G♯及B♯减七，双升降拼写。
- B7原位及三种转位、Cmaj7第三转位；名称和转位数字相符。
- C大调中的D♯／E♭，C♯大调中的E♯／F，C♭大调主和弦。
- 小调的两种级数参照。
- 六和弦／小七歧义、外音低音和加九低音采用明确的人工解释。

23份谱分别检查即时结果、所属和弦、顶部摘要、详情、谱面描述与供其它工具读取的分析。逐份保存，关闭最后一谱再开下一谱。检查程序保存了实际谱面与面板截图，说明使用对应图片。

## 原有操作与结果

- 和弦保留与人工排除、范围手柄保持真实音乐位置、关闭设置后编辑范围。
- 改音后人工范围保留，插入小节后复核、撤销与重做，实际MSCZ保存和重新打开。
- 摘要／详情／谱面样式分别设置、关闭重开恢复，当前版本及作者标识。
- 最终原生整组7项检查加初始化与结束，共9项通过；23份谱在其中逐个核对。记录：`P2/out/harmony-109-final-pluginhost.txt`。
- JavaScript上下文、显示、区间、导入导出及人工谱例五组通过。另用2500组音组比较优化前后全部候选和备选，结果相同。

## 耗时和接下来的工作

同一组5000帧、各三次，本机Node中位耗时从约1066.6ms到1006.4ms。按音级预先排除远离结果的候选，并复用和弦的音名字母间隔；这组记录用于比较本次计算变化。

C1-A本批处理音名、转位和换谱。C1-B接着检查和弦边界、旋律经过音、新低音、持续音和踏板残音，再到C2对位、C3演奏判断、C4松手导出。实体键盘按用户安排稍后接入，录制与声卡检查继续保留。
