# 选两颗音调整对应，再使用演奏力度

对应个人版本0.96.0 · Kumo branch / Freddd13。

## 导入和选择范围

1. 在谱面选要处理的段落，打开“视图 → 演奏表达”。
2. 点“当前选区”，核对目标行的小节、谱表和声部。处理整首可点“全谱”。
3. 点“导入 MIDI”。完整演奏也可以用于几小节选段；软件先寻找这段，再显示对应和力度。
4. 若“演奏片段”列出几处相似时间，选择本次要用的那一次。

新材料默认采用100%演奏力度，并逐音保存固定力度。列表里的“80 → 66”表示使用后这个音以66播放。比例改为50%时，会取原力度与演奏力度的中间值。

## 两边分别点音，改正一处对应

1. 在结果中点“查看对应”，或在“更多操作”点“在编辑器调整对应”。
2. 在上排“谱面”点要修改的音，再到下排“演奏”点实际弹下的那次起音。上排选择会保留，谱面也会选中同一个音。
3. 工具行下方写出两边的音名、小节拍位和演奏秒数，例如“谱面 D4 · 第1小节 第2拍 → 演奏 E4 · 1.000秒”。
4. 点“连接这两音”。下面的对应和拟采用力度随之更新。已经明确对应的音显示“这两音已对应”；有疑问的已有配对可点“确认这两音”。
5. 想让前后音也围绕这一处重新对应，在“更多”里点“固定这一处对应”。“解除对应”把当前谱音留到“漏弹”中，方便重新选择。

鼠标在对应区时，Ctrl+Z撤销上一处对应或预览调整，Ctrl+Shift+Z重做。“更多”里也有同名操作。使用到谱里的修改，由乐谱的撤销操作恢复。

## 试听和使用

“谱中效果”听当前乐谱，“拟采用效果”听准备使用的力度和速度；正在听的一项会亮起。“停止试听”结束播放。

1. 采用单音：点相关谱音，应用范围选择“选中音”。
2. 采用一段：在谱面选范围，应用范围选择“当前选段”。
3. 采用其余结果：选择“全部已对应范围”。
4. 核对“使用力度”旁的音数，再点击。对应区也能直接点“使用力度”；速度对比时同一处显示“使用速度”。

每次采用对应一次乐谱撤销。采用后的音从“待使用”收起，其余结果继续保留。需要核对其它声部以外的演奏时，列表显示“其它演奏音”，可查看音名与秒数。

## 保存和继续

- Ctrl+S保存已经采用到乐谱里的力度和应用前的恢复记录。
- “更多操作 → 保存表达项目”保存原始演奏、人工对应、时间选择及当前设置。
- 重开乐谱，再打开表达项目，可以接着处理剩余音。
- 导入文件或打开项目失败时，当前结果继续保留；按页面提示重新选择文件。

录制的完整步骤见[录完后继续操作](EXPRESSION_080_GUIDE.md)。固定／跟随力度和分批采用见[从完整演奏取一段力度](EXPRESSION_095_GUIDE.md)。实际检查及复杂装饰音的当前结果见[本批记录](EXPRESSION_096_CHECKS.md)。
