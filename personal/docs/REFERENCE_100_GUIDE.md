# 移动项目、找回原曲与取消读取

## 把乐谱和录音放在一起

可以这样整理一份编曲：

```text
这首歌/
  编曲.mscz
  音频/
    原曲.mp3
    伴奏.flac
```

在原曲参考中打开录音、建立片段关联，然后保存乐谱。以后复制或移动整个“这首歌”文件夹，保持里面的层级，软件会从乐谱附近寻找原来的音频。片段、内部对齐点、音量和遍次都能继续使用。

## 音频找不到时

1. 打开乐谱，再打开“视图 → 原曲参考”。音轨和已有片段会显示出来。
2. 在缺失音轨旁点“找回文件”，选择搬动或改名后的录音。
3. 读取完成后，原来的片段和谱段关联继续保留。选一条关联即可播放。
4. 若录音内容有变化，先听片段并调整起止时间，再在关联的“修改”窗口点“范围已核对”。
5. 保存乐谱，记住这次找到的位置。

![缺失音轨旁的找回文件](images/review-20261024/reference-missing-audio-100.png)

“找回文件”延续这条音轨的片段和关联。“打开”给当前音轨换一份录音，读取成功后重新设置片段。“添加”建立另一条音轨。自己改过的音轨名称会保留。

## 读取时继续操作

读取过程中，状态行显示正在读取的数量，旁边有“取消读取”。已有音频继续留在画面中。取消后可以接着使用它；新添加的音频会退出这次添加。

如果选错了文件或文件损坏，提示会写出文件名。当前已打开的录音、片段和关联会保留，可以重新选择文件。

读取时也可以查看另一条音轨。读取结果更新到发起操作的那一轨，当前查看的轨道继续保持自己的片段。

还没有打开乐谱时，也可以用原曲参考听录音。关闭再打开面板，软件会恢复上次的音轨和片段。建立谱段关联时，再打开乐谱并选定要比较的位置。

![读取状态与取消按钮](images/review-20261024/reference-reading-cancel-100.png)

## 对应反复中的不同遍次

例如，同一小节第一次和第二次经过时，想听录音中的不同处理：

1. 为两个录音片段分别建立关联。
2. 在各关联行点“修改”，将“播放第几遍”分别设为1、2。
3. 选择第二条关联，顶部选“一起播放”，再点“播放”，乐谱和录音就从第二遍的对应位置开始。

一房、二房和跳转后的出现次数按乐谱实际播放顺序计算。如果这段只有两遍，填入3时提示会说明已有遍数，回到“播放第几遍”调整即可。

片段跨过反复跳回的位置时，可以在跳转处分成两条关联，各自指定对应录音。三种播放方式见[从同一位置比较原曲和乐谱](REFERENCE_081_GUIDE.md)，多轨、片段修改和删除恢复见[操作步骤](REFERENCE_099_GUIDE.md)。

## 保存与恢复

停播后按Ctrl+S保存乐谱。建立关联、修改片段后可以直接保存，软件会先写入当前的原曲资料。音频本体放在原来的文件夹中，乐谱记录它的位置和关联资料。用“撤销片段修改”恢复片段或对齐点的调整，用“恢复删除”找回刚移除的音轨。
