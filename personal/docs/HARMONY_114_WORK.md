# C1-D：未确定和弦与谱面范围

0.114.0已安装，源码1be693cc9，发布定位personal-v0.114.0。

## 原因和修改

区间构建在结果未确定时直接丢弃音组，因此谱上没有问号可双击。现在保留三个以上音级的未确定复音，名称显示问号，继续使用原有的双击、指定、保存和撤销。

不同的未确定音组分别保留边界；单音、双音和休止的自动显示维持原样。问号在“和弦与级数”或“仅级数”两种显示下都使用单个修改入口。

面板手柄与跨谱行范围的原有行为已回查。通过实际按钮完成指定、拆分、合并、隐藏、撤销和恢复自动；在休止位置增加解释后保存重开。同步已有的应用、和弦、撤销和重做图标。

检查见[本批记录](HARMONY_114_CHECKS.md)，操作见[待指定和弦与范围修改](HARMONY_114_GUIDE.md)。下一项C2和声与对位，再按C3、C4、D、E、F推进。
