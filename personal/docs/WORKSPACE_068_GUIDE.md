# 固定一行的小节，整理分行

适用版本：0.68.0。

## 保留现在这一行的排法

1. 点这一行的任意音符或休止。
2. 从“视图 → 谱行锁定 → 锁定当前行”操作，或点编曲工具栏的锁图标。
3. 接着修改音符、文字或间距。这一行继续保留原来的小节范围，行内间距会重新计算。
4. Ctrl+S 保存；Ctrl+Z 撤销本次锁定。

![谱行锁定菜单](images/system-lock-menu-068.png)

## 一次整理几行

先框选跨行的小节，再点“锁定选中行”。软件分别固定这些行；框选到一行的一部分时，会包含这整行。

想重新安排时，选中相关小节，点“解除选中行锁定”。“解除全谱行锁定”用于一次释放本功能锁住的所有行。原先手工添加的换行、分页和分节继续保留。

锁定和解锁都能撤销。保存重开，以及在前面插入小节后，解锁仍能找到对应的分行设置。

## 保存与其它 MuseScore 版本

谱中采用常规的禁止换行与换行设置，打印和 PDF 继续按原有方式排版。官方 3.6.2 已实际打开测试谱并导出 PDF。

用普通版继续调整时，可以显示格式标记，选中禁止换行或换行符后删除，恢复自由分行。在本分支使用“解除锁定”可一起处理本功能添加的标记。

## 本版同时合入的更新

调试日志增加查找、复制和显示选项，日志窗口及原有钢琴卷帘支持切换语言后更新文字。同步翻译和工具脚本，并修正 Unix 启动链接的文件后缀。个人工作视图和工具入口继续保留。
