# 演奏表达与多小节播放检查

对应0.80.0。采用四小节、16个四分音符的独立钢琴谱，第三小节包含前两小节没有的D5。用计时输入产生演奏MIDI，通过真实Qt窗口、序列器与记录音符事件的音源检查操作。

## 复现与修复

- 录制结束后，16个音已对应，结果首行却位于第329像素，面板仅高180像素。日志为usability-080b-before-performanceeditor-run.txt。
- 试听、采用与对应结果现连续排列，录制或导入后显示这一组；180像素面板的结果首行位于第150像素。录制区提供“对应结果”返回入口。
- 点列表选中谱音后，“选中音”的数量曾仍为0。现用原生选音同步列表与谱面，并在范围切换时读取当前选择。播放中保留播放位置。
- “谱中效果”的按钮原来按original判断，宿主实际状态为score；现统一显示。播放状态合并为一行，停止后更新按钮。
- 原／新力度数字使用清楚的文字色。内置试听使用当前材料，项目保存继续由保存入口处理。

## 完整操作

1. 在内置180像素表达区录制16个音，停止后查看音名、拍位、原／新力度。
2. 点结果里的一个音，按“选中音”采用1个；再按全部已对应范围采用其余15个。
3. 保存MSCZ并重新读取，核对16个固定力度均为105，应用前力度记录均保留。
4. 撤销一次后保留第1个已采用音；再撤销一次，16个音恢复原来的保存方式与数值。
5. 四小节试听两轮，切换效果保留当时拍位；检查D5及段尾音的输出、段尾停止与再次开始。
6. 从界面导入MIDI并实际点击两种试听，核对按钮当前对象；播放中点结果不改变拍位，再直接使用所选音的力度。
7. 原曲参考三种联合播放方式各开始、停止三次，另检查准备时取消、自然结束和再播。

窗口显示、150%缩放、旧功能回查及安装文件摘要在交付记录中列出。检查使用程序内计时输入与记录音符事件的声音输出；实际键盘和声卡的使用检查继续按总清单记录。
