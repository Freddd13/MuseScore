# 从同一位置比较原曲和乐谱

对应个人版本0.81.0。

## 第一次把一段录音和乐谱对应起来

例如，要用录音8—12秒比较乐谱第3小节第2拍到第4小节末：

1. 打开“视图 → 原曲参考”，点“打开”选择音频。已有音轨时，点“添加”可以再放一条。
2. 在波形上拖出8—12秒的片段。下方的“开始”“结束”可拖动数值微调，也可直接输入时间。
3. 回到乐谱，选中第3小节第2拍开始的音，再按住Shift选到第4小节最后一个音。休止符也能用来确定范围。只选一个音或休止符时，范围就是它在谱上占用的时长。
4. 点“关联当前选段”。下方出现一条关联，列出谱段和录音时间；部分小节会写出具体拍位。
5. 顶部播放对象选“一起播放”，再点“播放”。乐谱和录音从关联的起点一起进入。再次点同一个按钮即可停止。

长音跨过起点时，准备阶段会读取它之前的延音线和踏板。在起点补上仍应发声的音，便于从这里听清和声。演奏表达中试听一个局部选段也从该段开始。

## 调整已有对应

先点关联行，再按下面的用途操作：

- **换乐谱范围：**在谱面选好新的音符或休止符范围，点“改为当前选段”。录音片段继续使用原来的起止时间。
- **改录音范围：**拖波形端点，或修改“开始”“结束”。
- **让中间位置也对齐：**点“内部对齐点”，把录音中的某一刻对应到谱中的一拍。例如录音10秒对应第3小节第4拍。录音或改编的快慢发生变化时，可以增加这样的点。
- **删除：**关联行有“删除”，音轨行也有“删除”；分别处理一条对应或整条音轨。
- **恢复刚才的改动：**点“撤销片段修改”；删掉整条音轨可用“恢复删除”。

更换谱段时，已有内部对齐点会清空；“撤销片段修改”可以一并恢复。自己改过的关联名称继续保留。

## 选择播放方式和音轨

“一起播放”的方式可在面板中选择：

| 方式 | 听到的效果 |
| --- | --- |
| 开头对齐，各自播放 | 同时开始，之后保留各自的速度，适合比较改编与原曲的感觉 |
| 跟随乐谱 | 录音按谱中速度和内部对齐点伸缩，音高保持 |
| 跟随选定音频 | 选定录音保持原有节奏，乐谱及其它参加的音轨跟着它走 |

跟随播放支持50%—150%的保调速度。片段与谱段长度相差较大时，提示会写出需要的百分比；可以调整片段或谱段长度，也可选择“开头对齐，各自播放”。

每条音轨的“联”决定是否参加一起播放；M为静音，S为联合播放时独听。每条参加的音轨需要有覆盖这段乐谱的关联。音频中的不同片段可以分别关联到不同谱段，也能把同一个录音片段用于多处。

顶部选“原曲”时，听当前选中的音轨；选“乐谱”时，听关联的谱段。面板得到键盘焦点后，空格控制当前所选播放对象。原曲的快捷键、与乐谱互相停止等设置见[播放器操作](REFERENCE_SPECTRUM_074_GUIDE.md)。

## 保存与重新打开

关联、音轨路径、内部对齐点、播放方式和音量随乐谱保存。播放中调整设置后，停播会补存这些改动，再按Ctrl+S保存乐谱。面板关闭或重载时也会先结束播放，再保存当前设置。

音频文件保存在原来的位置。移动谱子后若找不到音频，在相应音轨点“重新定位音频”，关联仍然保留。普通MuseScore可以读取正常乐谱；保留全部个人资料的文件继续使用本分支保存。

扒谱显示与播放选段可分别选择。要看整首，扒谱时间下拉选“整条录音 · 原曲时间”；要和卷帘一起缩放，选相应的“按谱对齐”片段，见[频谱范围与缩放](SPECTRUM_078_GUIDE.md)。
