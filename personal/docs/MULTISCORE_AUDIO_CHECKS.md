# 多谱、音源与停播后的连续检查

日期：2026-10-26。任务R1-B，接续0.123的卡顿排查。

## 找到的实际问题

四份谱之间反复画力度、播放、停止、缩放和切换，发现旧谱有时仍保留“正在播放”的状态。返回旧谱后，编辑器把画出的力度放在预览里，一直等待播放停止。

SF2和CFX都出现过。修复前的检查分别在第11轮等待十秒仍未提交；直接检查旧谱状态，又在返回第一份谱时发现它仍被标记为播放中。

进一步检查了声音线程与界面的交接。声音线程先写入停止状态，随后发送界面通知；快速换谱时，通知可能晚到。只清除旧谱标志后，连续操作还出现过播放按钮与实际状态不一致。因此本次一起处理完整的停止通知。

0.124的修改集中在`mscore/seq.cpp`及其头文件：

- 停止先完成声音线程的通知，再处理所属乐谱和界面状态，随后交接下一份谱。
- 主动停止和自然播完都清除所属谱的播放标志。
- 同步停止期间，排队的开始或循环通知按停止操作处理。
- 声音与界面共用的播放状态采用原子读写；音符、速度、踏板、力度和音源设置保持原有内容。

修复前记录：`source-score-final-sf2-pianoteq-pluginhost.txt`、`source-score-cfx-final-pluginhost.txt`和`source-score-sf2-pending-pluginhost.txt`。第一次仅清除标志的检查位于`source-score-sf2-fixed-124-pluginhost.txt`。这些早期结果继续保留。
