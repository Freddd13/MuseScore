# C3-B2-B2：备选指法与连续琶音

2026-10-27。源码已检查，尚未安装；当前程序仍为0.128.0。接着C3-B2-B3同音换指组合的时机，再到C3-B3具体路线与写法、C4、D、E、F。

## 原因与修改

C3-B2-B2源码：[ca100cf0a20e](https://github.com/Freddd13/MuseScore/commit/ca100cf0a20ed4d8ef450a21508dec19f9f78c38)；插件：[c3408839da28](https://github.com/Freddd13/Muse3Plugins/commit/c3408839da287939bcdb80d3f3cb5cb8405a367c)。尚未安装。

旧计算只读取单个1—5数字，`2(3)`和`[4]`没有参加指法判断。三个音写着`2(3)`、`2`、`3`时，因第一条被遗漏而放过了手指重叠。

新增独立文字读取，将单指、括号指法和备选指法换算为可用手指。原文字、记号外观和保存方式保持。五指匹配使用增广路，检查每个琴键是否各有可用手指；同音多声部合并后使用共同可用的指法。

松手计算在原有音域区间内，优先保留新起音及需要继续按住的音，再检查能保留的其它键。备选指法也参加同一计算。发生重叠时，说明列出具体音与指法文字。

本批检查同时按键的可用指法。连续指法路线和`1-3`换指时机按后续项目继续处理；MIDI导出保留原有数字指法路径，C4再统一备选资料。
