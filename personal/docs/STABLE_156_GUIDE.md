# 0.156个人稳定版：解压后开始使用

**0.156.0 · Kumo branch / Freddd13 · Windows x64**

2026-10-31已更新本机原安装目录，可继续打开原位置的`bin/MuseScore3Evo.exe`。现有布局、配置和Codex路径继续使用。下方解压步骤用于独立程序包。

## 打开程序

1. 把`MuseScore-Kumo-0.156.0-Windows-x64.zip`完整解压到E盘等有足够空间的位置。
2. 保存并退出之前打开的MuseScore。
3. 打开解压文件夹中的`bin`，双击`MuseScore3Evo.exe`。
4. 从“帮助 → 关于”确认个人版本为0.156.0；“帮助 → 个人功能说明”查看完整操作。

程序文件、默认音源、原曲播放组件、VST宿主和MCP2.7.2均在包内。Codex连接直接使用随包exe，Python运行环境已经包含。

已有的个人布局和设置继续使用。乐谱按原来的位置打开、保存；原曲录音继续使用谱内保存的文件位置。Pianoteq、CFX等音源沿用本机已安装的插件。

## 在新位置连接Codex

打开“视图 → AI连接”，点“配置Codex”，然后在Codex重新连接musescore。再点“检查连接”，确认显示当前谱名。

可以让Codex：“读取当前选段和MuseScore原生谱图，再说明你看到的声部和和弦。”后续比较、试听、采用及撤销见[读谱与采用](AI_CONNECTION_156_GUIDE.md)。

这个程序包只带当前MCP2.7.2运行文件。原安装目录及其中仍在使用的旧连接保持原样。

## 功能开关

本包沿用个人使用设置，`bin/kumo.ini`中的`enable_exp_feature=true`。需要收起个人工具时，退出程序，把它改为`false`并重新打开；之后改回`true`即可继续使用。具体步骤见[个人工具开关](SHARING_145_GUIDE.md)。
