# SF3 钢琴的首次播放

0.153.0 · Kumo branch / Freddd13。

载入SF3音源时，程序会提前准备首次钢琴播放需要的样本。准备完成后再开始播放，声音输出可以直接使用这些样本，播放光标和停止操作更及时。

## 怎样使用

照常在音源面板选择钢琴，等待音源载入完成，再按播放。音源、预设、共用钢琴和踏板设置继续按原来的方式使用，详细操作见[音源选择与运行方式](VST_088_GUIDE.md)。

在合成器中添加音源时，加载窗口显示准备进度，可以取消。取消后可重新添加；未完成的新增音源会退出列表。谱面音符与演奏数值保持原有内容。

第一次载入仍需要读取音源，准备工作发生在这一阶段。同一音源已经载入后，可以继续播放、停止、重播和切换乐谱。

本机首次钢琴输出从约2.56秒降到0.11—0.21毫秒；四份大谱连续编辑与播放的操作见[检查记录](SF3_START_153_CHECKS.md)。
