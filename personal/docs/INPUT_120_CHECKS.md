# 播放后面板无法点击：修复检查

0.120.0，2026-10-25。最终编译及实际窗口检查已通过，准备安装。

## 查到的路径

原曲单独播放时，在编辑器时间尺按下鼠标，再让编辑器所在窗口失去活动状态。原版处理应用整体失去活动状态，却遗漏了同一程序中切到另一个工具窗口的情况。复现时乐谱状态为普通状态2，符号面板为可用，鼠标仍由performanceRuler占用。其它工具收不到点击。

修改前的记录为player-120-focus-before-pluginhost.txt，在“编辑器归还鼠标”处失败。

本次补齐所在窗口切换时的手势取消。参数区空白定位也明确记录自己的画布，鼠标被其它对象接走时能正确结束定位。正常画布之间的鼠标交接继续保留。

## 检查内容

- 原曲／一起播放共八轮，包含手动停止、自然播完和再次开始。声音处理在独立回调线程运行。
- 原曲播放中，在时间尺、参数区空白、卷帘空白和数值轴分别按下鼠标，再切到其它工具窗口。核对鼠标归还、原曲暂停和符号组实际点击。
- 实际激活主窗口，再激活悬浮的原曲参考，检查由窗口系统产生的切换事件。
- 普通乐谱播放、时间尺／写音被播放打断、工作视图往返、实际重音添加、撤销重做继续核对。
- 正常拖动、选音、独立区域定位、踏板操作、原曲快捷键和重复播放另行回查。

首次旧检查停在悬停条件；随后保留实际单击、记号数量及撤销的检查，原有操作通过。组合检查还发现上一项留下的搜索条件，已在新检查开始时清空，随后独立运行与连续运行都核对。

本批专门修复面板点击。C2-C3开发内容已另存至E盘，后续回到原定顺序。
