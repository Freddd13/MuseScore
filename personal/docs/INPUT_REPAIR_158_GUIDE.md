# 滚轮改力度、继续编辑和停止原曲

适用版本：0.158.0 · Kumo branch / Freddd13。

## 滚轮调整后继续选音

1. 打开演奏编辑器，启用“滚轮调力度”。编辑器收起后，这个开关仍可用于谱面。
2. 将鼠标指向要调整的音并滚动。浮标显示音名、谱表、声部和调整后的力度。
3. 直接点另一个音继续编辑。刚才的力度会保存；连续滚动合为一次撤销。多选时，滚轮调整鼠标指向的音。
4. 正在滚动时按 Esc 可取消这次调整。Ctrl+Z 撤销已调整的力度，“编辑 → 重做”可再次采用这次调整。

播放时可继续调力度，停止后写入谱中。其它音的修改会保留；同一个音后来输入的新力度优先采用。平时按原方式保存乐谱即可。

拖动、停止播放或滚轮调整接续完成后，可以直接操作符号面板、原曲参考和谱面。拖过的力度保留在当前位置，接着点击的工具立即响应。

## 在谱面停止关联原曲

在原曲参考中打开“谱面播放按钮”。关联片段开头显示“原曲”，点一下播放；播放期间改为“停止”，再点一下立即停止。

同一位置关联了多个片段时，开始播放会列出可选片段。播放期间点“停止”直接结束当前片段。随后仍可重新选择并播放。

独立原曲播放停止时保留乐谱的播放状态；“一起播放”会结束乐谱和参考音频。

## 踏板播放设置

在演奏编辑器选择踏板，再点“踏板：SF2…”或“踏板：钢琴…”。设置窗显示当前乐器，可调整 SF2 原有方式或钢琴换踏板的时间。点“保存设置”写入，Ctrl+Z 撤销；点“关闭”返回编辑。

设置窗打开时会结束先前的拖动并移到前面。乐谱和编辑器可继续操作；再次点这个按钮会回到同一个设置窗。
