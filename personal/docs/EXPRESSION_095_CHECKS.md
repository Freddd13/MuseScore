# 完整演奏、选段与采用检查

对应0.95.0。B1正在进行，后续顺序见[完整进度](REWORK_PROGRESS.md)。

## 本批修复的原因

- 固定35毫秒起音组会拆开较慢的琶音；当前按录音的小间隔和组间间隔估计分组，各音原有时间与力度继续保留。片段尾部按最后一个实际音取范围。
- 长演奏中的rubato会逐渐偏离全曲平均速度。对应改用局部起音间隔，结合音高比较。
- 快速反复音漏弹后可能出现几条接近的对应路径；同音重触也可能被附近音抢用。本批比较完整路径、保留各起音组已有的对应，并将有疑问的位置写到相关行。
- “演奏片段”此前只在独立页面出现，内置表达页缺少选择入口。现在两处共用同一个控件，记录所选起始秒数；导入另一个文件重置旧文件的时间过滤。
- 原曲参考与符号面板的共同鼠标问题继续使用0.93修复，本批重新操作检查。

## 实际窗口与保存

1. 新建独立20小节钢琴测试谱，完整MIDI每次起音有三个音，琶音各相隔35毫秒，并带有速度与力度变化。
2. 选第9–12小节，导入完整MIDI。96个音全部对应到预期起音和力度，漏弹、多弹和待核对均为0。
3. 先采用一个音，再采用前两小节中的47个剩余音，最后采用另外48个音。每批一次撤销；段外演奏值保持原样。
4. 保存MSCZ并重新读取，核对96个音的实际力度与恢复记录；连续撤销与重做回到相应阶段。
5. 用两次相同演奏检查“演奏片段”：选择前48音均待核对；实际点击第二次的25秒位置后，48音可采用。保存表达项目并重新打开，继续采用同一时间位置。
6. 实际MusicXML与MIDI通过宿主读取；巴赫材料547对人工对应全部一致，包含真实MIDI文件的时间换算。
