# 音乐判断与 MIDI 松手：2026-10-15

本批先用具体钢琴片段检查结果，再记录计算方法和耗时。用户的九度／十度设置继续沿用。

## 手指保持和踏板保持

每个音分别记录写在谱上的长度、目前占用的琴键、踏板能维持的声音。相同琴键在两个声部出现时，按一个琴键计算。

当前一组音有多种分手办法时，保留最多四种可行办法，比较接下来的两组音。优先遵守用户和分手记号；自动分手参考实际需要保持的音、跨度、指法和下一组音的位置。已松开的旧音在后面继续由踏板保持，直到再次起音。

[钢琴指法研究](https://arxiv.org/abs/1904.10237)把连续指法作为序列建模，也讨论了个人差异。本项目采用可解释的小范围候选比较，计算结果显示具体琴键、松手位置和手位变化。

检查例子：C4先由右手保持，左手随后弹C2；长低音C2在踏板下提前松手，再弹左手中区和弦；用户指定左手时保留该指定；同时六个不同琴键与同音多声部分别处理。

## MIDI 松手安排

先为接下来的演奏寻找必要松手位置。处理条件包含踏板区间、旋律保护、手工演奏、同音重触和最短按键时间。随后为同手、同起音的一组音安排接近的自然松手时间；不同声部的新音也参与这只手的下一次起音判断。

随机变化沿用固定种子。整组共享主要变化，每个音再加很小的差别。预览同时显示原长度、拟采用长度、踏板和下一组音，文字说明要松哪个音、为何松手。

CC64的开关阈值采用[MIDI官方说明](https://midi.org/midi-1-0-control-change-messages)。只有两个稳定数值的开关流可使用，例如0与100；有连续中间变化的踏板流保留原按键长度。

## 和弦解释

每个位置保留少量接近的和弦解释，结合持续时间、新低音与邻近和弦，选择前后连贯的一条解释。人工指定和踏板内单和弦设置继续生效。备选名称随结果显示。

[符号音乐和弦识别研究](https://arxiv.org/abs/1810.10002)说明了结合区间划分和整段证据的价值。本项目使用已有轻量和弦模板和独立的传统评分；计算分成逐位置评分、回查选择和输出区间，界面可以分批执行。

例子：Am7之后出现C、E、G、A，再回到Am7时，可解释为Am7/C，同时保留C6供选择；单独分析中间一组时仍可得到C6。旋律经过音、新低音、转位、小调和扩展音已有专门用例。

## 对位和谱面提示

分解和弦音型作为自动建议显示，可由用户指定为独立声部。声部重叠按上下声部关系判断；严格对位单独检查反向进入的纯五度、八度。

规则对照[music21声部进行示例](https://music21.org/music21docs/moduleReference/moduleVoiceLeading.html)，用前后四个音呈现依据。谱面提示随选中的问题显示，点击可定位；设置中可关闭。
