# 调整频谱与标注列表的空间

从“视图 → 演奏编辑器”打开“扒谱”。在“原曲参考”打开音频后，选择要看的音轨。用“上下对照”把频谱单独显示，用“叠加对照”将频谱放到卷帘背景。

## 展开、收起和调整标注列表

1. 在频谱上点一个音，点“标注这个音”。下方的“标注列表 · 1”显示这一轨已有一个标注。
2. 点“标注列表”可收起或展开列表。没有标注时，空间留给频谱。
3. 上下对照时，拖频谱与标注列表之间的横向分隔条，给其中一边多留一些空间。软件会记住调整后的分配。
4. 点列表中的音可定位、试音。要写入谱子时，先在谱面选择音符或休止符及输入时值，回到列表选音，再点“输入乐谱”。按住 Ctrl 选择多个标注可输入和弦。
5. 选中标注后点“删除选中标注”。Ctrl+Z 撤销删除，Ctrl+S 将标注保存进当前乐谱。

列表的开关和高度属于个人界面设置。切换音轨时，列表显示这条音轨的标注；音高和时间随当前乐谱保存。

## 原曲与乐谱一起播放

每条音轨上的 **M** 是静音，**S** 是联合播放时独听，**联** 决定是否参加一起播放。亮起表示启用。右侧“删除”移除这条音轨，“恢复删除”取回刚删的音轨。

速度、音量均可拖动滑块，也可直接输入右侧数值。面板较窄时按钮会换行；高度较小时，可用右侧滚动条查看下方的片段与关联。音频时间轴下的横向滚动条用于移动正在查看的时间范围。

在“原曲参考”选中音轨，拖出音频片段，在谱面选择对应范围，点“关联当前选段”。从关联列表选中这一条，将播放对象切为“一起播放”，再点“播放”。同一个按钮变为“停止”，可同时结束音频与乐谱；准备音频期间也可点它取消。

“开头对齐，各自播放”让两边保持各自的快慢；“跟随乐谱”让音频配合乐谱；“跟随选定音频”让乐谱配合这条音频。不同长度的两边会分别播到自己的片段末尾。
