# 播放、和弦显示与音源入口

0.127继续修复连续打开工具时的稳定性。原曲、和弦、滚轮调力度和编辑器沿用原来的操作与个人设置。

## 从工具栏打开音源

1. 打开乐谱，在编曲工具栏点击“音源与效果”，也可从“视图”菜单打开。
2. 先选择乐器，再查看当前使用的SF2或VST。切换方法见[音源与效果](COMPONENTS_092_GUIDE.md)。
3. 关闭后可从同一入口重新打开。首次启动也会显示这个入口。

![编曲工具栏](images/TOOLBAR_127.png)

图中按钮依次打开已有编曲工具，鼠标停留时可查看名称。音源入口已修复首次建立菜单时遗漏的问题。
