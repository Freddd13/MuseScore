# C4-A2-A：导出分手与备选指法

2026-10-27。源码已检查，尚未安装；当前程序仍为0.128.0。继续C4-A2-B延音与同音换指，再到C4-B成组释放、C4-C完整预览与文件，之后D、E、F。

## 原因与修改

C4-A2-A源码：[f01de0b1455a](https://github.com/Freddd13/MuseScore/commit/f01de0b1455a1579c0ba7d95d4948f03f1a61c85)；插件：[2ca81aaf2d95](https://github.com/Freddd13/Muse3Plugins/commit/2ca81aaf2d95c27758ce2ec061f08feececec422)。尚未安装。

导出只读取单个数字指法。`2(3)`和`[2]`被跳过，按键数量和跨度都合适时，指法占用可能漏掉。分手读取只看直接附属符号，也会遗漏嵌套记号。

现在用与编配检查相同的`PianoFingering::choices`读取备选，允许的手指随实际MIDI来源传入共同手位模块。数字指法保留原有字段，多个指法说明取共同可用的手指；相互冲突的位置单独保留原音长。

指法有疑问的音继续作为物理琴键参加跨度判断，保持其按键；其余明确的按键仍可安排松手。明确的分手冲突与延音内变化继续在C4-A2-B核对。

分手读取补齐嵌套符号，沿用原来的音头／和弦身份和起止范围。插件仓库的导出源码同步了本体已有的两种踏板路径，本体本批保留这些路径。

## 实际谱例与操作

- 独立长音谱改为左手B3保持，随后C4、E4、G4起音；跨度8半音。B3标`2(3)`，C4标2、E4标3：导出因手指占用安排提前松手。
- E4取消指定手指后，3指可以继续保持B3，理由恢复自然松手。`[2]`与普通2指分别读到相同约束。
- 同一B3分别附2和3两条指法，输出保留原长度，显示具体冲突；另一只手局部指法疑问也单独处理，明确左手长低音继续释放。
- 嵌套在其它符号里的左手记号同时核对原生分配与实际导出来源。
- 五种指法谱例分别保存并重开，原指法文字保留；导出前后原谱内容状态、保存标志与撤销位置一致。
