# 0.168 用法、核对与后续

操作请从[个人功能说明](../USER_GUIDE.md)开始。“从编曲到定稿”包含逐音力度、切换 CFX、原生谱图和雕版例子。

## 这次改了什么

| 项目 | 改动 |
| --- | --- |
| CFX 与保存 | 打开谱面后在独立进程准备逐谱 CFX；当前配置仍留在文件。停播后接回已就绪的音源。播放时保存完成的滚轮力度，结束播放后按原方式撤销。 |
| 原曲资料 | 随包 FFmpeg 读取 M4A、AAC、Ogg Vorbis、Opus 和 AIFF。播放器、频谱、视频使用同一路径。路径以最终保存位置计算，相对路径优先，缺失时可找回。 |
| 频谱与窗口 | 加入固定、翻页和平滑跟随，调整中的节拍网格可拖或按毫秒微调。常用个人面板可收到底部。 |
| AI 与力度 | 原生谱图成为默认取图方式。编配建议按音及拍位显示真正发声的力度，支持比较、部分使用和一次撤销。 |
| 雕版与视频 | 新增符号位置、共同拍位和谱表分行工具。净书候选给出本谱原生前后图。视频取定稿页面，各自保留画幅与取景。 |

## 已核对的操作

- 连续打开各自保存了 CFX 默认和 Soft Player 预设的两份谱，打开窗口分别用时 8 毫秒和 5 毫秒，加载仍在后台进行。第二份谱接入同一播放引擎后开始播放，再切回第一份，按原来各自的预设恢复。
- 播放中修改选音的力度并保存。播放位置继续前进，重新读取文件可见新值。停播后的力度值和保存值一致，撤销恢复原值。
- 用六种扩展格式分别核对真实解码、跳到一秒后的样本和 440 Hz 频谱。搬动中文工程目录后按相对路径读取；缺失时另存副本仍保留最后位置和关联。
- 把频谱单独浮动，拖动设置区分隔条，切换显示与节拍、关闭设置、对齐两点、手动浏览后恢复跟随。声音继续时最小化，按底部小条停止，再恢复面板。
- D 大调谱的行中裁图包含谱号、调号、拍号，展开整行仍是原生 PNG。两枚原为 67 的音只有背景音降到 64，锁定音保持 67，部分采用对应一次撤销。
- 用双谱表乐谱试了力度记号位置、共用拍位留白、小节宽度、谱表间距及换行。原生前后图显示变化，预览和保存副本期间原谱不变。采用后一次 Ctrl+Z 恢复原来整行。
- Windows x64 主程序和 MCP 2.7.3 已构建。MCP 取图、查看器和相关接口通过检查。

## 随后的工作

逐谱音源重点观察厂商界面打开时的真实声卡切换。频谱按同一份录音与 WaveTone 核对低音、起音和倍频。净书用跨谱表琶音、表情记号、系统边界与跨行续弧逐步补充可调整的对象。力度规则与钢琴音源的力度响应分开处理，建议先按现有音源试听再决定。
