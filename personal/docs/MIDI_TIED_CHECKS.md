# C4-A2-B1：延音中途的分手与指法

2026-10-28。程序版本0.130.0。本批完成后段说明的时间读取与保护，下一项C4-A2-B2核对同音换指的实施时间及跳转边界。

## 已复现的原因

导出只读取起音音头上的分手和指法；单个分手查询还把整条延音中的换手统一标成冲突。后续指法未参加松手限制，反复的每遍也缺少相应说明。

三个新谱例在原处理下失败：指法位置前被提前松手、换手后仍按原手计算、原生反复没有后段说明。

## 修改与实际检查

- 沿延音线读取后续分手、指法与原文字，只保存数值及文本；写谱位置、实际导出位置分别记录。
- 每遍使用展开位置及现有暂停补偿。分手按时更新；自动松手、尾端拖动和允许范围读取同一最早位置。
- 完整谱例分别核对展开／不展开、暂停、两种踏板导出、保存重开，原谱保存状态及撤销位置保留。
- 实际打开对比，点C2，看到“第1小节第3拍”的说明；拖尾端到前面，仍保留到该处之后。截图已查看，说明在图下完整显示。
- 对应较短的实际松键、恰好在松键时的说明分别排除，按键范围内的说明保留。
- 第一轮5项通过6.660秒；扩展23项通过19.285秒，包含原有备选指法、分手、普通MIDI、面板与两份SF3。
- 补齐实际拖动、暂停和两种踏板后的14项通过4.085秒。普通MIDI仍为191字节，测试谱中6个满足条件的音提前松手。
- 两份SF3原、新输出最大差值均为0。实体声卡和键盘继续按B5／F安排。
