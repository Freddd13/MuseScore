# 0.46.0 音乐判断和松手安排检查

Windows x64、Qt 5.15.2，使用独立测试谱。安装位置为msvc.install_repair_0_46_x64，提交标记personal-v0.46.0。

## 实际操作与结果

- 原生P0整组23项通过：实际打开和弦与编配面板、后台分析取消、谱面提示避开另一面板的和弦、点击提示定位、隐藏提示、面板悬浮与重新停靠、MIDI导出对比。
- P1工具整组35项通过：演奏表达导入、录制、使用力度和撤销，音频拖入与面板内空格，原有方案保存、读取、链接分谱和主方案导出。
- 演奏编辑器整组53项通过：播放后打开、筛选与原力度线、重叠音拖动、快捷滚轮、P键盘、选中和播放颜色、分手折线、输入时值等。
- 用真实窗口发现并修复首次停靠宽度过窄：右侧面板按宽度分配，上方面板按高度分配；已有位置继续恢复。截图检查要求谱面、点击点及面板都位于可见区域。
- 长低音C2借踏板松手：导出从1999ms调整到441ms，500ms处的C4/E4/G4以虚线标出；左手继续保持的琴键从4个变为3个，跨度从31半音变为7半音。原乐谱与撤销记录保持原状态。
- 同一只手同时起音的自然松手时间接近；固定种子重复导出相同结果。0/100两级CC64可处理，含连续中间变化的踏板流保留原按键长度。
- 相同音高不同声部按同一物理琴键计算；当前分手比较接下来的两组音，人工指定仍优先。

## 声音比较

使用当前MuseScore_General.sf3离线渲染原MIDI与处理后MIDI。普通钢琴片段和长低音片段均逐样本一致；峰值分别为0.221801654和0.299471557，最大差值均为0。关闭裁剪的默认导出与旧路径字节一致。

渲染日志仍有原有Fluid析构时的QMutex提示，可定位到audio/midi/fluid/fluid.cpp的析构锁；本批比较均正常完成。真实键盘、声卡与其它音源的听感在相应设备上检查。

## 算法与耗时

- 编配规则38项通过，增加上下声部任意轨道顺序的重叠、分解和弦角色与严格风格的反向纯五八。
- 和弦上下文、拼写、转位、小调级数和区间分析用例通过；新增Am7—Am7/C—Am7与C6备选，以及导入N.C.后恢复自动识别。
- 10000个和弦分析位置约2.05秒，在工作线程中执行。逐步分析与一次完成结果一致。
- 1000小节／6000音的只读读取47批，最大1.116ms、总计46.542ms；演奏快照116批，最大1.871ms、总计137.965ms。
- 编配面板的实际读取峰值本次为5ms；在不同运行中为1–5ms。每批按耗时调整数量，继续记录界面响应。
