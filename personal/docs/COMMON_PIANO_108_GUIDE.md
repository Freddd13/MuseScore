# 所有乐谱共用钢琴音源

适用版本：0.108.0 · Kumo branch / Freddd13。

## 换谱时继续使用同一套钢琴声音

如果平时都用同一套 CFX、Pianoteq 或 SF2 钢琴，可以开启共用。此后打开和切换乐谱，各谱的钢琴自动使用这套音源、预设和乐器效果。其它乐器继续采用各自的设置。

第一次使用：

1. 打开乐谱，从“视图 → 音源与效果”打开面板，在上方选择钢琴。
2. 在“添加或更换插件”中选择已添加的钢琴音源，点击“用作此乐器音源”。首次添加可点“添加插件…”，选择本机的 VST 文件。
3. 点“打开音源”选择喜欢的预设，调整声音。
4. 勾选“所有谱子的钢琴自动共用”。当前声音成为共用声音。
5. 切到另一份谱，直接播放。面板上会显示正在使用的共用钢琴。

共用开启后，“打开音源”、载入／保存预设和“此乐器效果”都作用于共用声音。在一份谱中改了钢琴预设，切到其它参加共用的谱，也会听到更新后的声音。主输出效果仍按各谱保存。

软件按乐器资料识别钢琴。多架钢琴同时演奏时，各自处理按键、音量和踏板；换谱会复用已经载入的钢琴。

## 某份谱想用自己的声音

在这份谱中勾选“本谱使用自己的钢琴音源”，即可恢复它原来保存的音源、预设和效果。清除勾选后重新参加共用。这个选择随乐谱保存，也可用 Ctrl+Z 撤销。

混音器原有的音色框会显示“共用：音源名称”。从框里选择其它音色，也会让这份谱改用自己的音源；一次撤销可恢复刚才的共用方式和音色。

## 切回 SF2、恢复与关闭

- **使用内置 SF2：**把共用钢琴换成当前乐谱原来的 SF2 钢琴。各谱参加共用的钢琴一起更新。
- **恢复上个共用音源：**恢复刚才替换掉的共用音源，包括预设和效果。
- **所有谱子的钢琴自动共用：**清除勾选后，各谱恢复自己的声音。下次开启可继续使用上次的共用设置。
- **共用设置：**可给这套声音命名；“采用当前钢琴声音”可把当前谱选好的钢琴设为新的共用声音。

载入失败时，面板会写出原因，并继续用本谱原来的声音。可以重新选择正确的插件或直接点“使用内置 SF2”。

## 保留已加载音源怎样配合

“换谱时保留已加载音源”管理各谱自己的音源。开启后，切回该谱可继续用已经载入的实例；关谱时释放。共用钢琴本身会跨谱保留，开启共用即可使用。

面板列出闲置实例数量。“释放闲置音源”释放当前没有使用的实例，当前声音继续播放。之后再次需要被释放的声音时会重新载入。

## 保存、导出和撤销

共用声音保存到本机设置，重新打开软件后继续使用；各谱自己的音源和“本谱使用自己的钢琴音源”随 MSCZ 保存。保存乐谱时也会留下最近使用的共用声音记录，供检查声音来源。

音频导出使用该谱当前选择的声音：参加共用时使用共用钢琴，采用本谱音源时使用本谱设置。导出会另建实例，正在使用的音源窗口保持原位。普通 MIDI 继续保存乐谱的音符、控制器和原音色资料。

共用开关、预设和效果修改可在操作所在的乐谱中撤销、重做。保存乐谱后，Ctrl+Z 继续撤销最近的实际修改。

完整乐谱继续可由普通 MuseScore 打开；普通版按照乐谱保存的常规音色播放。分享时可同时说明自己使用的钢琴音源与预设。
