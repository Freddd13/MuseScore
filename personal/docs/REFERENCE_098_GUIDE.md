# 原曲播放、暂停与快捷键

对应个人版本0.98.0 · Kumo branch / Freddd13。

## 先听当前音轨

1. 打开“视图 → 原曲参考”，选择已有音轨，或用“打开”“添加”导入录音。
2. 顶部播放对象选“原曲”，点“播放”。按钮变为“暂停”，波形中的细线和时间数字显示正在听的位置。
3. 再点一次暂停。再次播放从这里继续。播放到片段末尾后，再点播放会从片段开始。
4. 面板获得焦点后，空格控制播放／暂停；按住空格拖动波形可以平移，松开后保持原来的播放状态。
5. Ctrl+空格控制选定的原曲。面板、快捷键和扒谱共用播放状态，可以从任一处暂停。

“原曲”听当前选中的一条音轨。音轨行的静音图标亮起时，先取消静音再播放。“一起播放”按各轨的“联合”和“独听”选择参加的声音。

播放中点波形可改位置；速度和音量可拖滑块，也可输入数值。开启循环后，先听完当前位置到片段末尾，再从片段开始反复听。对应段落的建立与修改见[关联操作](REFERENCE_081_GUIDE.md)。

## 让原曲和乐谱轮流播放

在“项目”菜单按需要勾选：

- **播放原曲时停止乐谱**：从原曲按钮、快捷键或扒谱开始听录音时，先停止当前乐谱。
- **播放乐谱时暂停原曲**：在谱面开始播放后，录音暂停，播放位置保留。
- **隐藏面板时暂停原曲**：收起原曲参考时暂停当前参考播放。

前两个选项各自保存，初始为关闭。选择“一起播放”时，乐谱和参加的录音按关联共同播放。

![项目菜单中的播放设置](images/review-20261023/reference-playback-options-098.png)

## 设置自己的快捷键

打开“编辑 → 偏好设置 → 快捷键”，查找“播放／停止选定原曲片段”，可改为顺手的按键。已有自选按键和主动清空的绑定继续保留。旧设置里还没有这一项、且Ctrl+空格空闲时，会补上这个默认键。

在播放器的文字框里，普通空格用于输入文字。回到谱面后，普通空格继续控制乐谱。联合播放也有独立的“联合播放／停止”快捷操作可配置。

## 保存和继续

音轨路径、片段、关联和音量随乐谱保存；停播后按Ctrl+S即可。播放配合开关和快捷键保存在个人设置中。音频文件保留在原来的位置，搬动文件后可用“重新定位音频”继续使用已有关联。
