## 操作改动

| 用户提出的问题 | 修改后的操作 |
|---|---|
| 选了哪段看不清，选其它音后范围丢失 | 顶部保留目标小节、拍位和谱表；“当前选区／全谱”主动更换；乐谱比较使用实际身份 |
| 浮动后操作不一致，设置难找 | 内外共用一套紧凑操作和滚动区；保留手动调整、速度比例、保持时长及循环均有入口 |
| 录制提示启用输入后难继续 | 面板直接显示 MIDI 输入开关与设备状态；失败原因写在当前面板 |
| 录制位置不清楚 | 首音起计时，谱面与卷帘共用实时位置，模糊位置标作“可能在” |
| 收起面板后录制结果不明 | 录制与文件保存继续完成，重新打开后显示对应 |
| 试听与其它操作脱节 | 设置、重新对应、录制和采用会结束当前试听；比较保持当前拍位 |
| 不知道怎么应用 | 使用力度／使用速度显示待更新数量，可按音、选段、全部对应应用；采用后退出待处理显示 |
| 编配类别只能选一个 | 类别多选，提供全选与清空，程度另外筛选，继续保留分析结果 |
| 每项建议都要手动打开差异 | 选中写法自动显示谱面差异，“谱面差异”按钮可开关 |
| 关闭保留指法后仍受旧指法影响 | 手部分配和指法路线一起采用这个设置；分手不确定时继续检查明确的手部音 |

工具区域现在随窗口一同伸展，保留拖动分隔条及各区域的高度设置。鼠标检查使用实际悬浮、恢复和选区操作，等待布局完成后继续。

## 算法与检查资料

实时位置比较音高集合、起音间隔和若干条可能路径，分别保留漏弹与多弹的选择；任意音高模式使用起音间隔。每次最多保留 32 条路径，向后比较最多 8 组音。起音组时间窗口结合目标节奏调整，密集的连续起音分别处理。

传统对应路线参照 [Parangonar](https://github.com/sildater/parangonar)，实现独立的轻量值数据计算。指法路线继续参照 [钢琴指法研究](https://arxiv.org/abs/1904.10237)，个人跨度、已有指法和手部标记参与比较。

合成输入已核对漏弹、多弹恢复、任意音高漏拍、快速起音、首音计时、结束条件、录制光标及保留选音。2 万目标起音中处理 1,000 组输入约 26 毫秒，这是匹配器单项测量。
