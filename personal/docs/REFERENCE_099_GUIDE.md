# 多轨比较、修改片段与保存

## 播放时比较两条录音

1. 打开“视图 → 原曲参考”，用“打开”导入第一条录音，再用“添加”放入第二条。
2. 分别选中音轨，为需要比较的录音片段建立乐谱关联。音轨行的链条图标控制是否参加一起播放。
3. 顶部选“一起播放”，选择要比较的关联，点“播放”。
4. 点某轨的静音图标可以立即关掉这条声音，再点恢复。独听图标用于只听选定的一条或几条参加的音轨。
5. 播放中点音轨名称，顶部“音量”就调这条轨；“总音量”调全部录音。切换查看音轨后，声音从当前位置继续。
6. 再点“停止”结束。开启循环时，下一遍继续使用刚才调整的静音、独听和音量。

“原曲”仍然只听当前轨。要改变哪些轨参加本次播放，先停播，再点相应的链条图标。删除音轨会先结束当前参考播放；“恢复删除”可找回刚删的音轨和关联。

## 同一谱段保留几种录音片段

例如同一小节想分别比较录音第一遍和第二遍的处理：

1. 拖出第一段录音，选好谱中的音符或休止符范围，点“关联当前选段”。
2. 拖出另一段录音，再点“关联当前选段”。两条记录都会保留，本次播放采用新片段。
3. 要换回第一段，在它那一行勾选“本次”。同一音轨、同一次谱面出现中有重叠的其它记录会退出本次播放。
4. 乐谱有反复时，打开关联行的“修改”，用“播放第几遍”指定第几次经过该谱段。不同遍次可以各用自己的片段。
5. 用“撤销片段修改”可以恢复刚才的建立、选择、范围、遍次或删除操作。

多条不同音轨可以一起对应同一谱段。一个录音片段也可以在不同谱段反复使用。

## 调整已经建立的片段

先点对应的关联行，让波形显示这段内容：

- 拖两端或改“开始”“结束”，调整录音范围。
- 在谱上选好新范围，点“改为当前选段”，调整乐谱范围。
- 点“内部对齐点”，把录音中的某一刻对应到谱中某一拍；例如录音第10秒对应第3小节第4拍。先分别定位这两个位置，再点“添加当前两个位置为对齐点”。
- 对齐点的时间可以拖动，也可以单击输入。点旁边的“删除”移除这一点。
- 点关联行的“删除”移除这条记录；“撤销片段修改”可以恢复。

更换乐谱范围后重新设置内部对齐点。调整录音端点时，仍在片段内部的对齐点会保留。

![保存后的多个片段关联](images/review-20261023/reference-associations-099.png)

## 保存后继续使用

停播后按 Ctrl+S 保存乐谱。音轨、关联、片段起止、内部对齐点、遍次、静音、独听和音量都随谱保存。重新打开乐谱后，从原曲参考里选择音轨和关联即可继续。

音频文件保留在原来的文件夹。移动或改名后，可选中音轨，再从“项目 → 重新定位音频”找回文件。
