# 频谱范围和时间缩放检查

对应0.78.0。使用独立八小节钢琴测试谱与24秒测试音频。把录音8—12秒关联到第3—4小节，另加录音11秒对应段落中间一拍的内部对齐点。

## 复现

修改前，首次打开自动进入第一条关联，实际选择下标为1；频谱放大后，编辑器可见范围仍为15360 tick。两项检查均失败，日志为`P2/out/usability-078-before-pluginhost.txt`。

## 操作检查

- 首次显示原曲时间；切换关联、整条录音和另一音轨后，保留各音轨选择。
- 用实际鼠标滚轮从频谱及卷帘缩放，检查滚动条范围、可见音频时间和缩放中心。
- 用匹配片段返回关联范围，平移到关联外查看提示，再切回整条录音。
- 在内部对齐点附近标注音高，缩放前后读回保存的录音时刻，并检查撤销。
- 在原曲时间叠加视图用卷帘滚轮缩放；检查频谱与音符同时变化。
- 上下对照、叠加、悬浮、恢复停靠和窄窗工具栏截图分别查看。
- 回查空格播放、循环、画标注、删除、撤销、估计时值及输入乐谱。

## 结果

- 主程序及Qt操作检查程序编译通过。
- 最终9项操作加初始化／结束共11项通过，日志`P2/out/usability-078c-final-pluginhost.txt`。
- 150%显示缩放3项操作加初始化／结束共5项通过，日志`P2/out/usability-078-dpi150-pluginhost.txt`。已查看窄窗工具栏与关联频谱截图。
- 放大关联片段时，频谱块从缓存取回，新增分析块数为0；内部对齐点缩放前后保存时刻均约11秒。
- 上一组回查中的标注长度检查使用了包含右侧留位的宽度，造成预期值偏差；随后未完成恢复的悬浮窗口影响下一项查找。现按实际绘图区计算，完整操作已走完，两个原失败日志继续保留。
- 使用独立Qt窗口、鼠标和按键检查；用户乐谱与音频保持原样。
