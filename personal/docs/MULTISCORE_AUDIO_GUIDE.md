# 同时打开几份谱，怎样安排钢琴音源

适用于0.124.0及之后的个人版本。

0.124修复了停播后迅速换谱、返回旧谱时力度预览一直等待的问题。停止会立即更新原来那份谱的播放状态，回去后可以继续编辑。

## 平时几份谱都用同一套钢琴

1. 打开“视图 → 音源与效果”，在上方选择钢琴。
2. 选好SF2、Pianoteq或CFX及其预设，勾选“所有谱子的钢琴自动共用”。
3. 切到另一份谱，直接播放。面板会写出当前采用的共用钢琴。

各谱的钢琴会自动参加。多架钢琴仍各自处理按键和踏板，同一位置的钢琴在换谱时复用已载入的音源。完整操作见[共用钢琴](COMMON_PIANO_108_GUIDE.md)。

“本谱使用自己的钢琴音源”适合某一份谱需要其它声音的情况；这个选择随谱保存。

## 每份谱需要自己的声音

在“音源与效果”勾选“换谱时保留已加载音源”，可减少返回原谱的载入等待。打开的谱越多，保留的音源越多，所用内存也会增加。

“释放闲置音源”会释放其它谱暂时不用的实例，当前声音继续使用。返回那些谱时重新载入。关闭乐谱也会释放属于它的独立实例。

本机四份谱的连续检查中，Pianoteq共用约333 MiB，保留四份独立实例约887 MiB；CFX Compact约768 MiB和1.19 GiB。这些是整套检查程序的内存，包含插件、乐谱及窗口，供选择使用方式时参考。其它预设的用量会不同。

当前已有设置继续保留。可以根据各谱是否需要不同的钢琴，选择共用或独立保留。

## 暂时不用和弦与原曲工具

从菜单或工具栏关闭“和弦助手”，会结束它的分析，清除所属的谱面文字、颜色和手柄。再次打开恢复原有显示设置。

听原曲时，选“定位”即可点选播放位置；要划片段时切到“选段”。“只播选段”决定是否限制播放范围，“循环”决定是否反复。互停和谱面片段播放的步骤见[原曲操作](PERFORMANCE_REFERENCE_123_GUIDE.md)。

多谱负载的实际检查见[检查记录](MULTISCORE_AUDIO_CHECKS.md)，完整待办见[当前进度](REWORK_PROGRESS.md)。
