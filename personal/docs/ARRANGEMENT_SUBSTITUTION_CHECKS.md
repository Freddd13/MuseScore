# C3-B2-B3：同音换指的时机

2026-10-27。本批源码已检查，尚未安装；当前程序仍为0.128.0。接着C3-B3具体指法、换手与配音建议，再按C4、D、E、F继续。

## 原因与修改

旧计算忽略了`1-3`中的起音手指，也没有检查3指何时空出来。这会漏报起音冲突，或把一个本来可以等短音松键后完成的换指判为困难。

现在分别检查起音和后续换指。计算比较其它音的实际松键、踏板允许的提前松手、下一组音和下一次明确记号变化；优先少松琴键，再选较早可完成的位置。下一组音也使用目标手指时，会继续比较稍后换指的安排。每项说明列出相关音与操作顺序。

同音多声部共享一个物理琴键和换指，重复的相同记号合并处理。预定松手到对应时刻才从手的占用中移除；选段、反复和后续音头的指法分别保存时间。普通数字指法跳过额外换指搜索。计算只接收数值资料，谱上指法、音符和实际MIDI继续由原有编辑操作管理。

## 实际检查

- 修复前用`1-3`与另一条1指音复现起音漏检，原生检查失败，见`substitution-c3-before-pluginhost.txt`。
- 原生用例核对起音手指、等目标手指松开、借踏板释放旧音、下一组音仍需目标手指、音长不足、多次换指，以及新的记号改变安排。
- 同音多声部覆盖相同换指、普通1指与`1-3`并存；25个不同按键和局部分手不确定时继续检查明确部分。默认自动分手保留可行的右手换指安排。
- 实际面板从打开、更新结果、选择提示到定位相关音完成操作。将C4指法改成固定1指出现冲突，撤销后恢复换指说明；缩短其实际按键长度后，说明指出E4仍占着目标手指。恢复后再检查正常。
- 独立测试谱设置两遍反复，主动保存、重新打开，两个出现位置继续使用正确指法和时间。原谱只读。
- 最后一组19个用例通过，连同初始化与收尾共21项通过，36.014秒。包含本批面板、备选指法、连续琶音、后续保持、跨延音、移动手位、实际MIDI和原有编配操作。
- 全部15组JS通过；其中新增5项核对下一次记号变化、反复时间、延音指法来源、多步说明及具体阻挡音。
