# 面板窗口与工具栏

对应正在检查的个人版本：0.72.0 · Kumo branch / Freddd13。实际发布进度见[操作检查记录](WINDOWS_072_CHECKS.md)。

## 把一个工具单独铺满屏幕

演奏编辑器、从“区域”中移出的工具、原曲参考和音源与效果，标题栏右侧提供“面板全屏”按钮。其它工作流面板可在标题栏右键选择“面板全屏”。

1. 打开工具，点击标题栏的全屏按钮。
2. 工具独占当前屏幕，继续选择音符、调参数或播放。
3. 再点全屏按钮或按 Esc，回到进入前的停靠位置或浮动尺寸。

先点击该面板，让操作焦点进入面板，也可用 Ctrl+Shift+F11 切换。浮动编辑器的“回到乐谱”会显示乐谱，工具可从原入口再次打开。

## 调整与组合区域

拖动面板边缘改变窗口大小。编辑器内部拖分隔条分配卷帘、力度、频谱和其它区域的空间。

“区域”入口放在编辑器工具页右侧。每个区域可显示、关闭、悬浮、放到右侧或放回编辑器。双击工具页标签可将相应工具悬浮。

窗口较窄时，工具栏按按钮文字宽度换行；操作较多时可在工具栏内滚动。音符、参数和频谱继续使用下方空间。“写节奏”页收起普通编辑参数工具栏。

浮动窗口在重新打开时检查当前屏幕位置。更换显示器或恢复旧布局后，窗口移回可见屏幕内。音源自己的 VST 窗口也会在重新打开时检查屏幕位置。

## 保存和返回

面板位置与区域设置保存在个人工作区中。切换工作视图或关闭程序时，正在全屏的工具先回到原位置，再保存布局。再次打开会使用调整好的普通尺寸。乐谱修改继续按普通保存和撤销操作处理。

## 调整 VST 界面里的参数

打开“音源与效果”，载入音源后点击“打开音源”。调节音源旋钮、预设或踏板设置时，宿主保留当前音源和窗口。关闭音源界面后记录参数；保存乐谱、换谱或关闭乐谱时，也会读取当前参数。

这次参数记录可用 Ctrl+Z 撤销。撤销音源参数会恢复该次调整前保存的音源状态。

首次打开时，先在“乐器”选择要使用的乐器。下方“VST 音源与效果列表”尚无内容时，点“添加插件…”选择已经安装的 VST3 或 x64 VST2 文件。扫描完成后，列表会标出每项属于音源还是效果。

选钢琴音源后点“用作此乐器音源”，再点“打开音源”调整预设。要回到选用 VST 前的 SF2 钢琴等音色，点“切回原音源”；“恢复刚才音源”可以再次取回刚切走的 VST。当前实际音源显示在列表上方。
