# C3-B3-B：换手、配音与对位候选

2026-10-27。源码已检查，尚未安装；当前程序仍为0.128.0。本批完成后接C4松手导出，再按D记谱与字体、E AI和分享、F完整交付继续。CFX厂商窗口鼠标操作按用户安排稍后检查。

## 原来的问题与修复

配音只比较问题总量，减少一个旧跨度时可能同时引入新的困难。现在逐处比较问题类型、相关音和反复次数，核对新和声、对位和明确的按键困难；同一低音提示继续比较具体音对、参考音区和实际共同持续时间。只有改善当前困难、同时通过这些检查的八度改法才列为候选。

旋律保护原来只认默认track 0；现在同时采用用户指定的其它旋律声部。对位参照补齐持续到当前位置的音，写入前检查也使用这些保持音；同一和弦中的重复音高继续核对。

换手试算现在真正增加分手资料，再按实际按键重新检查。同一时刻跨声部的变化合在一版中，保留已写明的分手。试算保持原音高、力度与实际演奏资料；谱面附加标记的手部信息单独列出。

## 采用回退与差异显示

换手候选在实际面板点“使用这版”时回退。逐项比较发现，差异显示先把预览里的分手符号永久改成主题蓝色，写入校验又比较了符号颜色；原谱实际添加的符号仍是正常颜色，造成两边不一致。

已修复绘图过程：颜色和选中强调在绘制完成后恢复原值，原来的写入核对保留。四次打开、绘制、关闭差异后，预览乐谱的记谱资料及所有相关元素、符杠的颜色和选中状态保持一致。

另一个操作问题发生在首次分析结束：结果已提交，面板未及时再次显示差异。现在任务完成时统一刷新结果与谱面。写法标题和变化列表按内容安排列宽，正常窗口能完整看到“分手 未标 → 左手”。

改变分手、参数或旋律保护后，面板更新当前建议的适用状态，并在原位置提示重新分析。外部改变该谱的演奏检查设置后，原生采用入口同样核对设置；恢复原设置后可继续比较。
