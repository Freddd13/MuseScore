# C1-B3／C1-C：分析导入、来源与临时显示

当前安装0.112.0；0.113.0正在检查。

## 查到的问题

- 导入的整段分析只写到面板的临时数组；谱内记录只保存人工修改和位置，关谱重开后导入部分丢失。
- 导入过程会先替换部分当前资料再检查位置；读取或写入失败时，面板可能已出现部分变化。
- 分析文件的结果提示混在配色组中，重开后也难以辨认当前解释来自文件。
- 按音乐内容保存的兼容缓存需要区分已经随谱保存的资料，避免另一份相同音符的独立乐谱读取到它。
- 当前乐器操作没有完整区分其他乐器的谱内记录；旧帧文件也丢失了原来的大小调解释。

## 实现

- 导入解释和人工修改合入现有谱内区间记录，继续使用schema 2、原生撤销和MSCZ元数据。区间保留导入／人工来源，隐藏范围及文字位置一同保存。
- 完成文件、范围和位置检查，并成功写入谱内记录后再更新面板。旧逐时刻文件转为明确区间。重复导入整理为同一组有效范围。
- “重新检测”移除导入解释，保留手动修改；它与导入均能一次撤销。按钮附近显示结果，状态与详情显示导入来源。
- 兼容缓存标出已经随谱保存的资料。旧版缓存继续读取，当前谱内资料按所属乐谱恢复。
- 导入、导出、重新检测及来源状态按当前识别范围处理，保留其他乐器的解释和位置。旧帧使用文件中的调性；显示、离调颜色和导出读取同一解释，保留用户原有外观设置。
- 临时显示、原生选择、播放、P键盘及实际PDF导出一起回查，使用同分辨率图像比较打印内容。

具体结果见[本批检查](HARMONY_113_CHECKS.md)，操作见[保存和重新采用和弦分析](HARMONY_113_GUIDE.md)。
