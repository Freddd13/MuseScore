# 连续试听、原曲与写法保存 · 0.148.0

## 本次发现与修复

从分段试写点“从同处听”后，声音开始播放，谱窗仍保持编辑状态。原播放键根据谱窗状态决定开始或停止，因此第一次点击会继续播放，等到片段结束才停止。修复让播放键优先检查实际播放状态，并在开始试听时同步按钮。本次同一流程中的停止耗时3毫秒。

在其它工具一起打开、可见谱面变矮时，还发现原有上下留白会挤出下谱表。现在整行能够放下时，按可用高度缩小留白，保持两谱表可见；整行确实高于可用区域时，继续显示谱行上部。

## F-C1-B1：同一首谱连续操作

使用独立八小节双谱表钢琴谱，从打开和建立A/B开始：

1. 在B修改音高、加踏板，从同处试听，用上方播放键停止，再切A、B。
2. 打开原曲参考，载入录音并关联全段；打开和弦助手，完成当前分析。
3. 导入包含64个音的完整演奏MIDI，显示对应及力度；开启原曲一起试听。
4. 在第二拍后从拟采用效果切到谱中效果，继续当前拍位。停止后再次进行两轮联合播放，分别在谱面按空格、从原曲面板停止。
5. 切到频谱，读取同一条录音及关联；返回演奏表达，采用64个音的力度105。
6. 切A再切B，B的力度保持105。保存MSCZ并重开，核对音符、踏板及力度。

原生检查保留文件在插件仓库P1/out/final-regression/workflow-sessions.mscz。声音检查读取实际输出缓冲；设备听感继续按原计划检查。

## 本次补充的两项反馈

第一行播放工具栏的“跟随谱面”复用原有开关。停靠、悬浮及关闭编辑器后，播放按真正可见的谱面计算；缩放与手调尺寸保留。

写法切换保留原有、新增、修改与删除后的踏板。音型和逐音演奏分别随写法保存，踏板与谱上共用演奏标记继续保留。撤销重做、链接分谱及保存重开已回查。操作见[播放跟随与踏板](FOLLOW_VARIANTS_142_GUIDE.md)。
