# C3-B2-B1：后续换指、分手与提前松手

2026-10-27。源码已检查，尚未安装；当前程序仍为0.128.0。接着C3-B2-B的连续琶音与特殊指法文字，再到C3-B3具体建议、C4、D、E、F。

## 原因与修改

旧计算只按当前音与踏板判断能否松手，遗漏了延音后段明确写出的指法、分手。选择较短范围时，后续音头还可能位于本次快照之外。

实际演奏分页现在为延音附带有指法或分手的音头资料，按乐谱内容版本复用。一次按键保留独立身份，后续说明按反复位置换算；普通MIDI的起音、松键和控制事件保持原样。

规则读取选区外已经生效的说明及后续指定位置。原生手位计算在指定位置之前保留按键，移动时间也使用同一约束。跨度说明写出后续小节、拍位和指法／分手，定位继续指向当前相关音。

分手资料转换整理为`handmarkers.h`，快照与实际演奏读取共用；仍覆盖附在其它符号上的分手记号。窗口、布局、保存流程和个人设置保持。

- 原生旧计算复现了错误的提前松手建议，`required-c3-key-before-pluginhost.txt`保留失败记录。修复后，指定位置之前及当时保留按键，之后可再次考虑踏板松手；可用移动时间从要求的时刻算起。

- 独立两小节谱例中，只读取第一小节；第二小节第一拍的2指仍参加判断。实际面板显示跨度和具体换指位置，点击“定位相关音”选中第一小节第二拍的新音。删除后续指法会更新建议，撤销后恢复。
