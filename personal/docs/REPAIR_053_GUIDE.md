# 0.53：插件重载与原曲关联

## 重载已经打开的插件

1. 打开和弦助手或其它插件，保留面板。
2. 打开“插件 → 插件管理器”，点击“重载插件”。
3. 软件重新读取插件，恢复刚才打开的面板；启用状态和快捷键继续保留。

正在录制 MIDI 或拖动时，重载按钮显示等待原因，结束操作后继续。面板关闭自己的内容时，其它插件继续显示。

## 原曲关联与重复播放

选中关联，在“原曲／乐谱／一起播放”中选择“一起播放”，点播放。结束后可以再次点播放。选音、调整外观、缩放或重新排版后，关联仍可以使用。

小节数量、时长或拍号改变后，关联行显示需要调整范围。点该行的“修改”，选中新的谱段并使用当前范围。

## 检查记录

修复前，在和弦面板打开时重载，窗口测试以访问异常退出。修复后的同一用例连续重载三次通过，同时检查进程正常退出。安装后的窗口操作共 13 项、P1 操作共 49 项通过，包含面板鼠标操作、播放、原曲多轨恢复、保存及关闭。两套测试程序均正常退出。
