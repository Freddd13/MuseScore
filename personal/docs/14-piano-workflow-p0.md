# P0 钢琴工具：宿主边界与合并定位

音乐规则在独立插件，宿主只提供自然入口、安全值数据和导出副本操作；不把规则放入音乐核心或音频回调。生产源码随宿主发布，插件源仓库保留同步锚点脚本。

## Tap BPM：独立测速 / personal-v0.23.0

运输／播放工具栏独立节拍器旁新增固定宽度 **TAP**。每次点击记录按下时刻，至少四拍正式估计；支持八分、四分、附点四分与二分单位，显示换算后的四分 BPM。下拉可 ÷2／×2／重置，只有点击“设为独立节拍器”才应用；跟随乐谱播放时不能应用，不写谱内速度。工具菜单有同一个 QAction，可在偏好快捷键中自定义，无默认抢占键。超出 20–400 的估值仍显示，应用受明确范围限制。长停顿重置，自动重复不计入，鼠标双击的两个按下分别计拍。

实现：单调计时、最近 12 间隔稳健中位数／MAD、停顿重置和单位换算；估算器与工具栏分离，共享菜单 QAction，没有音频回调改动。

验证：值测试 11/11（含 Tap 单位／停顿／稳健统计），真实共享按钮固定宽度／按下／双击／重复保护；继承原 pluginhost 12/12、scoreobserver 17/17。最终合并版本再做 Release 标识验证。
