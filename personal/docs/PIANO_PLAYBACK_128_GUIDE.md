# 切换乐谱时继续使用已载入的钢琴

本批修复共用钢琴在播放、切谱后重复载入的问题。多份谱来回编辑时，程序继续使用已准备好的钢琴；音色、混响等仍按你的设置工作。

## 开启共用钢琴

1. 打开一份钢琴谱，在“视图 → 音源与效果（VST）”中选择钢琴。
2. 选好要用的内置音源或 VST，调好预设。
3. 勾选“所有谱子的钢琴自动共用”。已有共用设置时，可展开“共用设置”，点击“采用当前钢琴声音”。
4. 打开另一份钢琴谱并播放，再切回前一份继续编辑。程序沿用已载入的共用钢琴。

若某份谱需要独立音色，在这份谱中勾选“本谱使用自己的钢琴音源”。取消后回到共用设置。原有选择随项目和个人设置恢复。

## 这次改了什么

CFX 等音源会把播放中收到的控制值记入自己的状态。例如，乐谱给出的混响数值会使当前状态与刚载入的预设有所不同。此前切谱时，这种差异可能引起再次载入。

现在程序分别记录载入的设置和当前演奏状态，切谱时正确复用共用钢琴。手动更换预设、调整音源或效果继续照常生效。

和弦助手、编辑器、滚轮调力度及原曲播放的入口保持原有位置。整体关闭和弦助手时，摘要、分析任务和所属谱面显示一起关闭；个人设置保留，下次打开继续使用。
