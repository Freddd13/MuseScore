# 用Codex读谱、看原图和采用建议

适用于0.156.0及之后版本 · Kumo branch / Freddd13；随包MCP2.7.2。

## 先确认正在讨论哪份谱

1. 在MuseScore打开乐谱，选中想讨论的小节。
2. 打开“视图 → AI连接”，点“检查连接”。下方会显示当前谱名。
3. 在Codex说：“确认当前谱名和选区，读取这段的音符和MuseScore原生谱图。”
4. 核对返回的标题、文件名和谱图，再提出编配要求。

谱面上实际显示的标题优先使用。旧文件的“作品信息”有时留着另一个名称，Codex会分别读到它们。原生谱图采用MuseScore当前排版，能看见延音、跨谱表音符、踏板及手动位置。

需要更换任务范围时，直接说清小节。想继续上一段，则说“继续刚才那四小节，保留原来的要求”；读谱工具会重新读取这一段，并保留任务说明。

## 比较、采用和撤销

可以这样说：“保留旋律和本段总长度，给左手两种更轻的写法，先让我比较。”

1. Codex准备建议后，MuseScore右侧“编配建议”显示写法名称、范围、变化和说明。
2. 选中写法，点“谱面差异”查看变化；用“试听谱中”“试听这版”比较声音。
3. 点“使用这版”采用，或者让Codex采用指定写法。
4. 按Ctrl+Z撤销采用，Ctrl+Shift+Z重做；Ctrl+S保存当前乐谱。

查看差异时，原谱内容保持原样。采用后变化写入当前谱，保存后下次打开仍可继续编辑。本版同时修正空音源设置在读取后被误存的问题，普通SF2乐谱保存时的撤销顺序保持连贯。

## 看懂连接列表

![分别查看实际版本和请求状态](images/ai-connections-156.png)

展开“Codex连接”，点击“刷新连接列表”。每行显示进程、MCP版本、启动时间、最近请求和活动状态。

- **MCP版本**：当前进程实际运行的版本。2.7.2提供身份、原生谱图和继续任务工具。
- **等待下一次请求**：这条连接已用过，现在空闲。
- **正在处理任务**：正在读谱或执行操作。
- **活动记录待核对**：程序已找到这个进程，尚未读到它的请求记录。先看版本列，再刷新列表。

每个Codex会话通常有自己的连接进程。结束已不用的那条会话后，可以在列表选中对应进程，点“结束所选连接”。正在使用的会话继续保留。

“停止读谱连接”控制MuseScore接收请求；“允许Codex启动MuseScore MCP”控制Codex下次是否启动连接。关闭这个说明窗后，现有连接继续可用。第一次配置和移动程序后的更新步骤见[连接配置](AI_CONNECTION_154_GUIDE.md)。
