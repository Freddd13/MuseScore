# R1-C：播放光标与缩放卡顿

用户补充：播放光标、缩放都明显变卡，同时开着滚轮调力度。本项先于C3继续。

## 操作与测量

四份600小节测试谱分别检查编辑器关闭、编辑器打开、滚轮开启、和弦与谱行带同时开启。每组持续播放12秒，在播放中滚轮改力度、Ctrl缩放。

随后只读复制《如果有来生-release5》为四份独立测试文件。铅笔调整一段力度后保留较大选区，每组持续播放30秒，穿插滚轮和Ctrl缩放。测试副本保存在E盘，原文件只读。

四组30秒流程的界面计时最长间隔分别为32.35、46.96、45.87、284.94毫秒。最后一组出现一次明显停顿，随后对同一组合持续播放90秒并记录界面调用，最长间隔76.13毫秒。严重卡顿尚未稳定重现，继续R1-C。

## 已确认并优化的开销

力度参考线在播放光标移动时反复计算和绘制整幅曲线与说明。现在复用透明图像；乐谱内容、力度记号、筛选、显示范围、尺寸或字体变化时重新建立。谱行带保持原来的绘制与编辑位置。
