# 安装说明中的链接检查

2026-10-30，在当前0.145安装程序上核对功能说明。

原有操作页和截图可以打开。继续进入历史记录和开发资料时，有166处链接依赖开发目录或指向源码；分享程序文件夹后，这些位置无法按原路径找到。外部字体专用滑音的一份说明也漏在安装包之外。

现在发布说明时保留本地操作页和截图；源码、字体研究及历史图片目录使用对应仓库中已存在的提交链接，由浏览器打开。字体操作章补入本地说明。用户电脑继续按菜单打开功能说明。

已生成独立预览，递归核对200份文档和可达的本地链接。导出工具同时检查目标文件、图片、循环链接、中文路径、代码例子，以及尚未发布的资料；原始源码文档保持原样。

已在真实安装目录完成导出，再次读取200份文档和1040处本地链接，缺失项为零。检查同时覆盖安装目录位于源码目录下的常用方式；程序、个人开关和随包MCP保持原校验值。

开发者使用：

```powershell
python personal/tools/package_user_guide.py "程序安装目录" --report "检查结果.json"
```

说明导出由发布时完成。程序使用者直接从“帮助 → 个人功能说明”阅读。
