# 0.162 频谱检查

N6按“选录音 → 浏览／缩放 → 取音 → 参考线 → MIDI对照 → 播放 → 保存”检查。使用独立测试谱与生成录音，用户原谱保持原样。

## 已核对的结果

- Windows实际控件：参考线菜单、数量修改、琴键强调、设置区分隔条和收起、上下／叠加、卷帘与浮动时间尺定位、空格暂停继续、MIDI显隐及对齐保存。三个新场景均通过；逐张查看频谱与设置截图。
- 原有操作：关联范围选择、片段内外定位、缩放与滚动、长录音末尾取音、连续写谱与撤销、循环中改变听辨参数、调律移调、演奏起止及MIDI轨道编辑。七个连续场景均通过。
- 三分钟WAV、VBR MP3、FLAC：90秒附近首屏185–248毫秒；同位置缩放包含通知等待约61–62毫秒，内部调律／音域映射6毫秒；120秒范围准备1.7–2.6秒。测试将内存缓存设为8MiB，实际使用8000KiB。
- 40秒整轨共10块后台准备后，浏览后段无需新FFT；取消保留已有图像。长录音取消约91毫秒，换录音只发布新文件的结果。
- 低音A0、立体声反相、重采样、倍频位置、突出基音、静音／错误来源、节拍估计、听辨滤波及磁盘淘汰一起检查。其它缓存资料保持原样。

代码与输出：`mtest/mscore/spectrum/tst_spectrum.cpp`、`mtest/mscore/pluginhost/spectrum_162_tests.inc`；原始日志和截图在插件仓库`P2/out/repair-162`。
