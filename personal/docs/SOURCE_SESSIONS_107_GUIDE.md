# 换谱时保留已加载音源

从0.107起，可以让仍然打开的乐谱保留各自的音源。比如给A谱载入CFX，切去B谱编曲，再回A谱时直接使用刚才的CFX和预设。

1. 打开“视图 → 音源与效果”。
2. 给当前乐器选择音源、载入预设。
3. 在“正在使用的音源”里勾选“换谱时保留已加载音源”。
4. 切到另一份谱，给它选择需要的音源，再切回原谱。

返回时会恢复这份谱的音源、效果和预设。原谱的按键和踏板在切走时释放，旧效果尾音也会清理。厂商窗口在切走时关闭，回到这份谱后可再点“打开音源”。

![音源保留设置](images/review-20261024/source-sessions-107.png)

“释放闲置音源”旁显示保留了多少份谱、多少个音源和效果。把鼠标放在数量上可以看到谱名。点击后释放已经切走的谱所占用的音源，当前谱继续使用；再回到其它谱时按其保存设置重新载入。

关闭一份谱会释放它保留的音源。取消勾选会立即释放闲置音源，以后换谱沿用原来的释放方式。此设置自动记住，程序初次使用保持关闭。

保留中的音源占用内存，闲置期间停止处理声音。内存紧张时可以释放闲置音源，或关闭暂时不用的谱。更换声卡采样率后，音源会按新采样率重新建立。

这里保留每份谱各自的声音。各谱使用同一套钢琴时，可开启[所有谱子的钢琴自动共用](COMMON_PIANO_108_GUIDE.md)。多谱的用法和实际内存比较见[多谱音源安排](MULTISCORE_AUDIO_GUIDE.md)。
