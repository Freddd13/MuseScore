# 0.129.0：编配检查、指法建议与 MIDI 松手

本次把近期检查过的修复编入程序。版本为 **0.129.0 · Kumo branch / Freddd13**。

## 检查一段钢琴是否容易弹

在谱上选中要检查的范围，打开“编配检查”，点击“更新结果”。点一条结果可查看涉及的音、前后拍位、分手和指法。修改谱子后再更新结果。

本版会读取实际起音、松键、踏板、延音中的分手与换指，并考虑下一组音之前手指何时腾空。数字、括号和备选指法一起参与判断。详细例子见[按实际按键检查](ARRANGEMENT_PHYSICAL_GUIDE.md)、[前后手位](ARRANGEMENT_MOVEMENT_GUIDE.md)与[同音换指](ARRANGEMENT_SUBSTITUTION_GUIDE.md)。

## 比较另一种指法、分手或配音

选段后打开“编配建议”，选择建议类别并点击“分析选段”。点击建议，谱面直接显示差异；先试听，再点击“使用这版”或保存为另一种写法。采用后可用 Ctrl+Z 撤销。

本版修复了差异绘图改变符号资料、导致采用失败的问题；首次生成会直接显示第一项差异。比较写法时保留用户指定的旋律，逐处核对新旧问题。详见[比较换手、音区和声部写法](SUGGESTIONS_CANDIDATES_GUIDE.md)与[指法建议](SUGGESTIONS_PHYSICAL_GUIDE.md)。

## 导出时安排提前松手

导出 MIDI 时勾选“人性化裁剪”，打开对比窗口，查看细轮廓的原长度与实心条的新长度。点音符可查看提前松手或保留的具体原因；确认后返回导出。

本版按真实松键时间判断手位移动，读取嵌套的分手记号、括号和备选指法。某音指法存在冲突时保留该音，其余明确按键继续检查。详见[实际按键与前后衔接](MIDI_RELEASE_PHYSICAL_GUIDE.md)与[已有分手和备选指法](MIDI_FINGER_GUIDE.md)。延音中途换指和反复的更多导出情况仍按完整计划继续补查。

## 选择音源运行方式

打开音源面板，载入 CFX 或 Pianoteq 后，在“运行方式”中选择“直接运行”或“独立运行”。直接运行适合低延迟弹奏；独立运行把厂商窗口放到另一个进程，可减少窗口对谱面操作的影响。44.1 kHz 下会增加约 11.6 毫秒延迟。

切换会保留音色、参数和效果；正在播放时先停在当前拍位，准备好后可继续播放。Ctrl+Z 可以撤销这次切换。共用钢琴沿用[所有谱子共用钢琴](COMMON_PIANO_108_GUIDE.md)的设置。

CFX、Pianoteq的四种本谱／共用组合已检查声音、切换、保存重开和撤销；厂商窗口的真实鼠标焦点操作待桌面可用后补查。
