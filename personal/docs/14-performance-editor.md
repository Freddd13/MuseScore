# 14 演奏编辑器：力度、速度与踏板

## 方案与实现范围

更新到个人版本 0.8.0 后重新检查了插件观察器、临时屏幕标注和原卷帘。观察器适合分析/显示；无法独立提供可靠的谱面手势捕获、原生属性事务、主窗口保存前提交和播放渲染同步。因此采用独立原生面板，后续人性化/随机化等算法仍可放在插件。保留原卷帘，不重写音高、谱面时值或 MIDI 音序器。

本次源码主要在 `mscore/performanceeditor/`。乐谱继续使用原 `Note::veloType/veloOffset`、`TempoText` 和 `Pedal`；没有新序列化字段或外部演奏数据副本。主窗口仅创建 dock、转发当前谱/选择；ScoreView 仅增加屏幕绘制入口。底层整数百分比助手在 `libmscore/notevelocity.*`，原 MIDI 渲染流程保留。

## 使用

在“视图”菜单打开“演奏编辑器（力度 / 速度 / 踏板）”。可以停靠或浮动。上方音符块供参考/选择，下方切换三种参数；当前乐器包含钢琴双谱表，也可选择当前谱表、全谱和声部。

- 力度：拖柱；选中多音后拖其中一柱整体偏移。铅笔/直线按时间画值，有选音时仅影响选音。右键附近柱可区分同一时刻的和弦音。数字框写入选音。
- 显示轴与存储模式独立：MIDI 轴调整后仍保留原相对/绝对类型；“转换为相对/绝对”才转换类型。相对值是整数百分比，转换保持首个 Note-on 的力度到可表示的最近整数。低基准值可需要大于 100% 的偏移，检视器范围随模式调整。
- 速度：四分音符 BPM，5–999；画线落到已有 ChordRest 时刻，保存原生隐藏 TempoText，显示实际阶梯。已有可见速度标记受保护，明确单击节点才可改它。数字框可改选中节点；保留可解析的原拍单位、描述文本，关闭 followText 后同步文本数值和播放值。画一段后在下一已有时刻恢复原速度，避免影响后文。
- 踏板：拖画原生开关区间，或拖已有端点；起点吸附目标谱表 ChordRest 起点，终点吸附其实际结束边界（含整小节休止），避免原生 Pedal 自动校正后显示/保存不同。同一乐器的双谱表共用踏板。拒绝与其他已有踏板重叠；支持 CC64 开/关，不添加半踏板自动化。
- 全曲/选区定位，Ctrl+滚轮缩放时间轴，普通滚轮横移；属性改变后保持当前时间视口。Esc 取消当前手势，“取消预览”取消全部暂存。

“音旁手柄”和“谱行参数带”独立开关，首次打开关闭。手柄只在悬浮/已选音旁出现，固定屏幕尺寸；浮动带位于谱面视口底部，其横坐标跟随当前谱行的实际排版。它不占记谱布局空间。输入/文本编辑/照片模式/打印时隐藏；点击手柄和参数带以外继续交给原谱面。

## 数据与播放边界

相对力度公式是 `base + base * offset / 100`，整数运算后截断到 1–127，不能改成加法偏移，也不能提前把基准截断。基准从音符自己的谱表、事件起点、演奏法和全局/谱内动态渲染方法得到。多次发声显示范围；不独立发声的隐藏、延音后续音和合并装饰音不提供直接编辑。整音属性仍作用于该音的所有演奏事件，不伪造独立事件力度。

播放中调整力度仅保留面板橙色预览，当前播放和检视器仍使用已保存值。停播且后台 MIDI 渲染结束后一次 undo 提交。保存/另存/关闭/换谱前 flush 会停止并等待渲染；外部改谱使快照失效时取消预览，避免覆盖新值。速度与踏板停播后编辑。

总谱与分谱的速度/踏板沿用原生链接命令。力度的 VELO_TYPE/VELO_OFFSET 在本版本原属性表中明确不链接；分谱编辑力度保持原生独立行为，不强制传播到总谱。

TempoText 本来会反复 fixTicks；新增临时批事务，用成对 UndoCommand 边界包住原生链接元素命令，在执行/撤销/重做结束时统一重建。深度和待重建标记只存在内存，没有改谱文件。切勿以裸 addElement 代替 undoAddElement，否则分谱同步会丢失。

排版/对象销毁回调通过指针索引使快照失效，读取谱行前检查内容状态；不调用正在析构的元素的虚函数。仅在编辑器手势持续期间安装应用事件过滤器捕获 Esc，结束即撤除，避免 MuseScore 主窗口过滤器绕过局部键盘处理。

## 维护入口与验证

| 入口 | 职责 |
| --- | --- |
| `PerformanceEditor::refresh/updateSelection` | 停播时构建快照，模型/排版/选择失效；音符按 tick 有序，可见范围二分查询 |
| `beginGesture/moveGesture/finishGesture` | 屏幕预览、手势事务和单次提交 |
| `applyPending/flushForScore` | 播放/渲染空闲和保存边界 |
| `ParameterEdit::velocities/tempos/pedal` | 原生属性及 spanner 的 undo 命令 |
| `NoteVelocity::effective/offsetFor/referenceBase` | 整数百分比、最近可表示转换和逐音基准 |
| `mtest/mscore/performanceeditor` | 数值、原生撤销/持久化、MIDI 和真实主窗口手势 |

验证结果和本机部署以 [更新日志](../CHANGELOG.md) 当前条目为准。GUI 自动化不代替真实声卡、长时间人工编曲与复杂实谱验收。性能测试必须区分全曲概览、局部视口、快照重建和拖动提交，不能只给单音计算速度。

后续可加插件曲线算法、半踏板或真正独立事件力度，但须先定义其与原模型/导出/动态播放的语义；不在此版静默加入另一套数据。
