# 14 演奏编辑器：力度、速度与踏板

## 方案与实现范围

更新到个人版本 0.8.0 后重新检查了插件观察器、临时屏幕标注和原卷帘。观察器适合分析/显示；无法独立提供可靠的谱面手势捕获、原生属性事务、主窗口保存前提交和播放渲染同步。因此采用独立原生面板，后续人性化/随机化等算法仍可放在插件。保留原卷帘，不重写音高、谱面时值或 MIDI 音序器。

本次源码主要在 `mscore/performanceeditor/`。乐谱继续使用原 `Note::veloType/veloOffset`、`TempoText` 和 `Pedal`；没有新序列化字段或外部演奏数据副本。主窗口仅创建 dock、转发当前谱/选择；ScoreView 仅增加屏幕绘制入口。底层整数百分比助手在 `libmscore/notevelocity.*`，原 MIDI 渲染流程保留。

## 使用

在“视图”菜单打开“演奏编辑器（力度 / 速度 / 踏板）”。可以停靠或浮动。布局为紧凑工具栏、音符区、带小节拍位数字的时间尺、参数区与状态栏。中间分隔条独立调整两区高度，比例保存在 performanceEditor 设置组。下方切换三种参数；当前乐器包含钢琴双谱表，也可选择当前谱表、全谱和声部。

- 力度：拖柱；选中多音后拖其中一柱整体偏移。铅笔/直线按时间画值，有选音时仅影响选音。音符与对应柱默认共享蓝→青绿→黄→红的力度渐变。右键重叠音或柱可按谱表/声部选择候选，不使用虚假时间偏移。数字框写入选音。
- 显示轴与存储模式独立：MIDI 轴调整后仍保留原相对/绝对类型；“转换为相对/绝对”才转换类型。相对值是整数百分比，转换保持首个 Note-on 的力度到可表示的最近整数。低基准值可需要大于 100% 的偏移，检视器范围随模式调整。
- 速度：四分音符 BPM，5–999；画线落到已有 ChordRest 时刻，保存原生隐藏 TempoText，显示实际阶梯。已有可见速度标记受保护，明确单击节点才可改它。数字框可改选中节点；保留可解析的原拍单位、描述文本，关闭 followText 后同步文本数值和播放值。画一段后在下一已有时刻恢复原速度，避免影响后文。
- 踏板：拖画原生开关区间，或拖已有端点；起点吸附目标谱表 ChordRest 起点，终点吸附其实际结束边界（含整小节休止），避免原生 Pedal 自动校正后显示/保存不同。同一乐器的双谱表共用踏板。拒绝与其他已有踏板重叠；支持 CC64 开/关，不添加半踏板自动化。
- 全曲/选区调整时间视窗；“视窗…”提供音域、定位选音、音域概览、音高行高、参数范围缩放/移动和完整/数据范围复位。初始音高行高 12 px，优先居中选音；窄键条与半音行对齐，C 行显示八度。放大后块内显示音名，“显示…”可开启力度数字。
- 两区横向完全一致。Ctrl+滚轮缩放时间；Ctrl+Shift+滚轮缩放当前区纵向；Shift+滚轮横移；普通滚轮在音符区移音高、参数区移数值范围。参数分别记忆 MIDI、相对%、四分音符 BPM 与踏板开关视窗，视窗不改属性值。右侧音高滚动条与“视窗…”按钮提供鼠标操作。
- 单击替换选音，Ctrl+单击切换；空白拖动框选，Shift 追加、Alt 减选，松开才一次写入原生选择。选音保留播放位置，停播默认试听（可关闭）、不创建 Undo。力度柱选音也同步谱面、检视器与原卷帘；拖已选柱保留多选组。
- “声部…”支持 1–4 多选、过滤外声部淡色参考和独立的“选择这些声部”。默认使用已有原生时间范围选区，否则当前视窗；也可明确选择当前视窗或全曲。当前乐器覆盖双谱表，每谱表声部号按原生 track % 4。过滤不清空谱面选择，状态栏只统计可编辑选音；参考音不命中、不写入。
- 音高行使用 Note::ppitch 实音（含八度线）；块内按原生 tpc1 拼写。悬浮同时给出原生记谱拼写/八度、实音/MIDI、乐器、谱表/声部、原生小节拍位、时值、保存值/预览值/整数舍入后实际力度，音符与柱同时强调。
- 时间尺单击/拖动定位，拖动中仅显示橙色预览线，松开才定位。播放线贯穿两区与时间尺，默认到右侧约 85% 时滚页并保留约 12% 前文；手动滚动、缩放或编辑暂停跟随，“跟随：暂停”按钮恢复跟随并重新定位，下次开始播放自动恢复。
- “显示…”选择力度/声部/谱表着色、调整渐变节点与分类颜色、背景/网格/文字/选择/播放/预览/参数色，可恢复默认。仅改编辑器外观，设置重启恢复，不写谱面颜色。亮边框为选中，绿色独立描边为发声，橙色虚框为待提交预览；颜色可自定。
- Esc 取消当前手势，“取消预览”取消全部暂存。

“音旁手柄”和“谱行参数带”独立开关，首次打开关闭。手柄只在悬浮/已选音旁出现，固定屏幕尺寸；浮动带位于谱面视口底部，其横坐标跟随当前谱行的实际排版。它不占记谱布局空间。输入/文本编辑/照片模式/打印时隐藏；点击手柄和参数带以外继续交给原谱面。

## 0.11 交互补充

面向用户的完整操作见 [用户功能说明](../USER_GUIDE.md)。播放按钮和画布空格走 ScoreView 原生 play 命令；空白单击定位、双击从该处播放、移至选音是明确定位入口，点选音符仍保留位置。停播试听走原生定时 startNote，使用实音、调音与保存的实际力度，播放中不插入试听。

两区分别提供 −／+、音域／选音、匹配值／全范围；参数滚动条和数字轴拖动只改变数值视窗。匹配值优先可编辑选音，否则当前视窗。Alt 拖音符块以位移调整力度。端点距离优先、柱体上的原选音优先、完全重合单击轮换／Alt 轮换／右键候选共同解决同刻多音，不偏移真实时间。

`performanceoverlay.cpp` 隔离谱面浮动层：双向悬浮、原生选音端点强调、音名／谱表／声部／拍位／数值标题、播放线和鼠标线。只连接已有 viewRectChanged/scaleChanged；native QWidget::scroll 复制旧像素后，补重绘旧浮层及平移副本，连续滚轮事件累计损伤区域，不修改 ScoreView 滚动实现。旧默认整套配色自动升级为灰色，用户自定义配色保留，可显式恢复新默认。

## 0.12 滚轮与宿主入口

Evolution “其他选项”工具栏固定个人按钮复用 View 菜单的 QAction，populateAlternativeOperations 每次重建只添加一次，放在该栏首位，窄窗口优先显示；旧工作区也可见，无需扩展 Shortcut 表或改变原工具栏列表。图标是本地 SVG 音符块／力度柱／播放线。

`performancewheel.cpp` 负责可开关单音滚轮、Alt 临时入口、Shift 8／普通 1 的轴单位步长；Ctrl 与横向滚轮不接管。原生音头仅 Alt，手柄／参数带／编辑器是显式编辑面。复用 noteEditable、hits、setNoteValue、_pending 与原生提交，没有另一份音乐数据。原生多选不变，滚轮仅当前目标；相对百分点和 MIDI 显示轴保持原存储类型及整数舍入。

300 ms 单次计时器合并滚轮段；小角度和像素滚轮累积到整步，同一光标位置锁定初始目标，避免端点降低后丢失。_wheelValue 累积轴目标值，_wheelBefore 仅用于 Esc 回退当前段，不丢失此前播放预览。改变目标／鼠标按下／模式切换提交一次；flush、销毁、外部内容状态改变停止计时器并解除临时应用过滤器。播放／后台渲染沿用已有延迟提交，持续滚轮时 applyPending 不抢先提交。高频事件只预览，不生成播放事件。画布内 badge 浮标只重绘目标音、对应柱和浮标区域，避免 QLabel 每值变化引发全窗布局或平台 Tooltip 窗口刷新；谱面浮标加入已有损伤区域，结束时清除。自有力度提交仅在原生撤销宏确认为本次目标的 VELO_TYPE／VELO_OFFSET 且没有其他命令或嵌套事务时增量更新 raw／type 和内容状态；力度不改变演奏基准，不重新生成全曲事件。外部改谱、撤销、缺基准或不符宏均完整刷新，排版仍单独修复。源码和 GUI 回归在原独立模块与测试目标内。

启动／帮助品牌在 [开发流程](07-development-workflow.md) 说明，与上游音乐模型无关。

## 数据与播放边界

相对力度公式是 `base + base * offset / 100`，整数运算后截断到 1–127，不能改成加法偏移，也不能提前把基准截断。基准从音符自己的谱表、事件起点、演奏法和全局/谱内动态渲染方法得到。多次发声显示范围；不独立发声的隐藏、延音后续音和合并装饰音不提供直接编辑。整音属性仍作用于该音的所有演奏事件，不伪造独立事件力度。

播放中调整力度仅保留面板橙色预览，当前播放和检视器仍使用已保存值。停播且后台 MIDI 渲染结束后一次 undo 提交。保存/另存/关闭/换谱前 flush 会停止并等待渲染；外部改谱使快照失效时取消预览，避免覆盖新值。速度与踏板停播后编辑。

若第一次打开面板时已经在播放，仅从稳定的原生音符属性建立轻量快照，不重新生成演奏事件，也不读取正在更新的力度基准。已有相对音可在相对轴预览，已有绝对音可在 MIDI 轴预览；缺基准的跨轴转换暂不可用，悬浮明确显示“基准待停播”。停播后补齐真实基准并按原属性提交，不猜测有效力度。

总谱与分谱的速度/踏板沿用原生链接命令。力度的 VELO_TYPE/VELO_OFFSET 在本版本原属性表中明确不链接；分谱编辑力度保持原生独立行为，不强制传播到总谱。

TempoText 本来会反复 fixTicks；新增临时批事务，用成对 UndoCommand 边界包住原生链接元素命令，在执行/撤销/重做结束时统一重建。深度和待重建标记只存在内存，没有改谱文件。切勿以裸 addElement 代替 undoAddElement，否则分谱同步会丢失。

内容状态改变才重建播放/力度快照；乐器/谱表/声部过滤复用快照，选择通知仅同步标记。排版变化只修复位置和 System 映射；音符销毁清理区间/链接索引，读取谱行前检查内容状态。音高分行区间索引有最大结束时刻前缀，包含在视窗左侧之前开始、仍在延续的长音。绘制、命中、框选复用音符矩形；密集概览聚合普通音，选中/悬浮/发声/预览仍独立绘制。静态网格与音名按视窗/DPI 缓存，播放只请求旧、新线和发声音附近的区域。参数绘制对完全相同位置、数值及样式的重复标记只绘制一次，每个源音符的命中/候选、选择与事务索引保持独立；不同值、不同配色和状态仍区分。

播放刷新只在面板可见、Seq 正在播放当前 masterScore 时启用 16 ms GUI 定时器。记谱 tick = repeatList.utick2tick(Seq::getCurTick())，心跳事件 tick 不作为播放线来源；心跳仅更新状态和 activeNoteEvents，经原生 Note 链接索引映射到分谱。换谱、隐藏、关闭、停止清理定时器/发声状态。停播定位使用 setPlayPos，播放中使用原卷帘一致的 tick2utick + Seq::seek 规则。

新 Score::selectNoteList 预校验全部目标和焦点、去重，复用 selectSingle 更新输入上下文，Selection 批追加只更新一次列表。原 Score::select() 不改；GUI 选择桥通知宿主一次，不调用 endCmd、seek 或试听；编辑器交互另行调用原生 startNote 试听，桥接层保持纯选择职责。相互通知有重入保护。每个仍打开乐谱的时间/音高/参数视窗仅内存保存，销毁时移除。高频参数鼠标移动以 16 ms 合并最新位置，释放先处理最终位置再一次原生提交。

对象销毁回调不调用正在析构的元素的虚函数。仅在编辑器手势持续期间安装应用事件过滤器捕获 Esc，结束即撤除，避免 MuseScore 主窗口过滤器绕过局部键盘处理。

## 维护入口与验证

| 入口 | 职责 |
| --- | --- |
| `PerformanceEditor::refresh/updateSelection` | 内容快照、独立布局修复与原生选择标记 |
| `performanceview.*` | 共享时间映射、独立数值视窗、持续音区间索引、三画布和背景缓存 |
| `performancepainting.cpp` | 音名/键条/真实小节拍位网格、参数轴、共享命中几何、状态配色 |
| `performanceinteraction.cpp` | 声部过滤、框选/重叠候选、缩放、悬浮、播放线/跟随/定位 |
| `performanceselection.*` / `Score::selectNoteList` | 不移动播放位置的原生批选与宿主通知 |
| `performancewheel.cpp` | 单音滚轮段、细粗调、原生事务预览及生命周期 |
| `performanceoverlay.cpp` | 谱面浮动层、双向悬浮、播放／鼠标线与滚动损伤修复 |
| `performancesettings.*` | 独立外观设置与配色对话框 |
| `beginGesture/moveGesture/finishGesture` | 屏幕预览、手势事务和单次提交 |
| `applyPending/flushForScore` | 播放/渲染空闲和保存边界 |
| `ParameterEdit::velocities/tempos/pedal` | 原生属性及 spanner 的 undo 命令 |
| `NoteVelocity::effective/offsetFor/referenceBase` | 整数百分比、最近可表示转换和逐音基准 |
| `mtest/mscore/performanceeditor` | 数值、原生撤销/持久化、MIDI 和真实主窗口手势 |

验证结果和本机部署以 [更新日志](../CHANGELOG.md) 当前条目为准。GUI 自动化不代替真实声卡、长时间人工编曲与复杂实谱验收。性能测试必须区分全曲概览、局部视口、快照重建和拖动提交，不能只给单音计算速度。

后续可加插件曲线算法、半踏板或真正独立事件力度，但须先定义其与原模型/导出/动态播放的语义；不在此版静默加入另一套数据。
