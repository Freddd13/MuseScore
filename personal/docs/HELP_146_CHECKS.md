# 帮助导航与说明检查 · 0.146.0

## 发现和修改

旧帮助窗口缺少返回、前进和查找。Qt的Markdown显示没有建立小标题链接的位置，点击后仍停在页首。帮助显示移到独立的userguide.cpp，补齐原生导航、本页查找和小标题位置，图片随窗口宽度调整。

源码索引中的旧行号、组合函数、测试名称和九条缺列记录已逐项整理；指向MCP的记录使用实际相邻仓库路径。检查脚本识别六列格式并报告具体行，同时检查三个项目的实际文件。

## 实际操作

- 从帮助菜单打开发布说明，点击“播放跟随与写法中的踏板”，再返回功能列表。
- 前进、返回后保持刚才的阅读位置；点击小标题、查找两处文字、从末尾继续查找、查看未找到提示。
- 调整窗口宽度，图片保持比例并在可见区域内显示；页面文件缺失时保留当前内容；关闭后重新打开同一个窗口。
- 阅读前后选音、播放位置、修改状态和撤销位置一致。
- 按用户补充复查停靠／悬浮／关闭编辑器后的跟随、完整播放两次、A/B踏板修改及保存重开、链接分谱与共用演奏标记。
