## 本轮问题与结果

| 用户提出的问题 | 现在的操作 |
|---|---|
| 频谱缺少颜色，叠加难看清 | 显示页提供蓝金、绿紫、灰阶与自选色；灵敏度、对比度和叠加浓度采用滑块配数值框 |
| 分开显示没有键盘 | 左侧使用与卷帘相同的键形与音高映射，可以点按试音；纵向放大后显示更多音名 |
| 空格不能播放、播放状态分散 | 频谱内空格控制原曲；共用音轨选择和播放位置，速度为滑块与数值框 |
| 不知道如何移动、后面有什么 | 底部时间滚动条、右侧音高滚动条、手形与中键平移；设置区可滚动和收起 |
| 每次滚动重新计算容易卡 | 按固定四秒块保存分析，缩放平移复用；配色和显示增益通过图像查表更新 |
| 想分辨基音和不同音域 | 谐波参考线、可混合的基音强调；听辨页提供均衡与按选频听 |
| 想跟拍、看网格、估计速度 | 原曲／乐谱网格、拍号与第一拍、速度候选、半速／倍速、跟拍与 Shift+空格 |
| 想画标注、修改时值再写谱 | 画起止、拖端点与主体、删除恢复；可按标注长度输入常用或附点时值，显示目标谱表和声部 |
| 独立窗口难关闭或退出不稳定 | 继续支持悬浮、右侧和放回；修复退出期间重新挂接窗口的 Qt 焦点问题 |

标注和节拍随 MSCZ 保存；一次拖动、删除或输入可整体撤销。配色、听辨和面板选项保存在个人设置。原曲仍在外部文件中。

## 方法与资料

交互参考 [WaveTone 使用说明](https://ackiesound.ifdef.jp/doc/wthelp/htuse1.html)的频谱、节拍与听辨方式。显示与声音控制分别放在对应页面。

频谱继续使用 Hann 窗与对数音高。基音强调采用倍频能量支持度，参考 [Essentia 的音高显著度说明](https://essentia.upf.edu/reference/streaming_PitchSalienceFunction.html)，提供原始与处理结果的连续比较。均衡使用独立实现的双声道 biquad，系数依据 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)。

速度估计比较频谱起音变化与周期关系，返回少量候选和第一拍。人工跟拍、半速／倍速与拖动第一拍用于校正。钢琴踏板、重叠声部或弱起会影响估计，可直接在网格上核对。
