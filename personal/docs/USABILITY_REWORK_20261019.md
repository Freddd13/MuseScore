# 最近新增功能：完整使用检查与返工记录

日期：2026-10-19。

用户对近期新增和修改功能的整体验收未通过。工作视图、编辑器、辅助工具、播放器、录制、VST 等全部进入本轮重新检查。此前的发布和测试记录作为实现历史保留。

本文记录用户怎样完成一件事、当前哪里中断、返工后怎样检查。修复状态按每条完整操作更新。用户提供的十张截图保存于 [本轮图片目录](review-images/20261019/)。

## 当前优先处理

用户补充：先修打开后跑到可见区域外、难以缩放和展开的问题。各新工具应能独立打开、关闭、浮动、全屏和返回原处，也能按当前编曲工作组合。CFX 界面持续刷新、无法聚焦点击属于阻断使用问题，需检查实际窗口、插件通知和状态保存过程。

## 3. 三条需要先重新串好的操作

### 录制与演奏表达

1. 先显示目标谱段、小节拍位、谱表和声部，可改为当前选区或全谱。
2. 输入设备与当前收到的音放在录制入口旁。录制中显示可能对应的谱位，停止按钮保持可见。
3. 停止后自动整理对应，保留录音。直接显示谱中音与演奏音，并在同一谱位对比原、新力度。
4. 已对应、漏弹、多弹、需核对可直接切换；点击一个音即可看到另一边及谱面位置。修正放在对应处完成。
5. 试听明确显示当前听到的对象，保持位置切换。采用范围、力度比例和使用结果放在一起。
6. 采用后显示改了哪些音，保留剩余结果；一次采用可撤销，原力度随谱保存并可恢复。

### 原曲与联合播放

1. 左侧选音轨，当前轨的文件、静音、独听、音量和删除就近显示。
2. 在波形选片段，旁边显示起止时间。关联行显示准确谱位，可修改、定位和删除。
3. 选择“原曲／乐谱／一起播放”，开始前能看见当前片段与参与轨道。
4. 同一处播放、暂停和停止；快捷键与面板焦点行为一致。停止、循环结束或关窗后可以直接再次播放。
5. 对齐微调直接反映到当前关联，保存重开保持；不同音轨允许对应同一谱段或不同谱段。

### VST 与 SF2

1. 先显示当前乐器与当前音源。音源选择中能清楚辨认 SF2 和已安装的 VST。
2. 尚未扫描时，显示添加音源的入口和查找位置；扫描中显示进度与可取消状态，结束后选择可用结果。
3. 选用音源后可以直接打开界面、试音，当前路由和载入问题在同处显示。
4. 切回 SF2 与选择 VST 同样方便，核对原音色、音量和声音；撤销可回到上一状态。
5. 音源、此乐器效果和主输出效果分别呈现。效果的旁通、顺序、删除与预设操作靠近对应对象。
6. 保存乐谱后重开，继续核对音源和声音；找不到插件时保留已保存设置并提供重新定位入口。
