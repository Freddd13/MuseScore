# 0.64.0：工作视图、独立编辑区域与字体

本次完成完整方案的第二批。用户操作见 [工作视图与区域摆放](WORKSPACE_064_GUIDE.md)。第一批的实验开关、内置 AI 连接与随包 MCP 继续提供。

## 实际改动

| 用户提出的问题 | 本版操作和结果 |
|---|---|
| 编辑器第一次打开，力度区消失 | 修复旧零高度布局；首次打开保持原窗口大小，参数区恢复可用高度 |
| 编辑器占用高度和工具区不灵活 | 四种工作视图分别保存布局；DAW 铺满；区域可收起、悬浮、放到右侧、放回 |
| 浮窗难回谱面、拖动易吸附 | 标题栏提供回到乐谱；菜单提供保持悬浮 |
| 工具入口难找 | 编曲工具栏复用视图菜单动作，包含和弦、原曲、表达、频谱和建议 |
| 演奏表达颜色与编辑器不协调 | 编辑器内跟随编辑器配色，移出后跟随软件主题；采用 Qt 当前字体 |
| 和弦启动后需要手动分析 | 先显示当前位置结果，后台补齐；准备状态明确显示；摘要与详情共同选择实时或所属结果 |
| 长设置挤占和弦修改 | 修改和弦与范围上移；功能色、音旁文字、外观分组折叠 |
| 多音频无法删除、播放对象不清 | 逐轨删除和恢复；原曲播放当前轨；联合列选择参加的轨 |
| 速度音量像按钮 | 原生滑块配直接数值输入，避免数值与加减按钮重叠 |
| 速度音符比 3.6.2 小 | 对默认 Leland Text 的节拍符号使用 3.6.2 兼容字形，保留其它字体和文字设置 |

另外修复了主窗口创建时工具栏访问顺序、AI 服务自动启动、首次打开表达页被布局恢复覆盖，以及快速切换视图后区域状态被延迟恢复覆盖的问题。清理重建工具栏时的旧控件。
