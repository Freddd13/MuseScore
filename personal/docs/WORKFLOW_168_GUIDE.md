# 从编曲到定稿

## 给一段旋律腾出空间

1. 在谱上选中旋律音。旋律交到左手时，也把左手的旋律音选进来。打开“视图 → 编配建议”，在“标记选中音”中选“旋律”。陪衬音可标为“背景”，低音可标为“低音”。选中必须保留的音时，标为“锁定”。
2. 圈出整句，点“力度建议…”。可以突出旋律、收轻背景，也可以为一句设置抬起、句峰和收束。已有细致演奏时，可以从 2–4 个力度单位的小调整开始。
3. 点生成的建议，谱面会定位到对应段落。表格里的 **67 → 64（−3）** 表示这枚音实际发出的 MIDI 起音力度。相同音高在不同拍位可以有不同角色。若谱子有反复，展开每次发音能看到相应变化。
4. 点“力度对照”在演奏编辑器查看原值和建议值。用“试听谱中”和“试听新写法”比较。勾好要保留的改动，点“使用勾选改动”；整条合适就点“使用这版”。
5. 按 Ctrl+Z 撤销刚采用的建议；满意后保存乐谱。力度调整沿用原来的固定或跟随方式，原来的渐强和力度记号仍可继续编辑。

也可以问 Codex：“读第 9–12 小节的原生谱图和演奏数据。锁定第 9 小节第一拍的主旋律，把我标成背景的音各减 3，先给我一个可试听的建议。”Codex 返回的建议在同一个编配建议面板查看和采用。

## 让 Codex 看到你正在读的谱

在“视图 → AI 连接”点“配置 Codex”。确认连接的是这份谱。配置会检查净书资料与钢琴演奏力度资料。力度案例对应研究包 `piano-expression-0.3.3`。

打开一份有调号的谱，选中一段后问：“显示这段 MuseScore 谱图，先读谱号、调号和拍号，再逐拍说明我标出的旋律。”默认图片由 MuseScore 绘制，样式、谱号、变音记号和来源谱一致。段落从行中间开始时，同时附上该处有效的谱号、调号和拍号。想同时看前后环境时可请求“查看原生整行”。

有几份谱或多个窗口时，先让 Codex 报出**窗口、谱名、总谱或分谱、当前选区**。改谱后，请它重新读取。连接和进程管理见 [AI 连接](AI_CONNECTION_133_GUIDE.md)。

## 整理一页谱，再输出 PDF 或视频

在顶部工作视图选“雕版”。当前乐谱进入页面显示，并打开右侧“雕版工具”。切回编曲时，继续使用这份谱原来的工作视图。

| 要调的位置 | 操作 |
| --- | --- |
| 文字、表情记号、曲线 | 选符号，切到“符号位置”，填写水平和垂直移动量，再点“调整选中位置”。正数向右或向下。 |
| 上下两手同一拍的空隙 | 选该拍的音符或休止符。切到“横向间距 → 共用拍位”，改“拍位前增减”。移动的是上下手共用的时间列。 |
| 一个或几个小节的宽度 | 选中小节，切到“横向间距 → 所选小节”，调整“小节宽度”。100% 使用通常的宽度。 |
| 谱表间距与行间距 | 选目标谱表上的音，在“谱表与分行”选下方位置并填最小距离。选中该行后可锁定或解除锁定。 |

例如，第 12 小节首拍的转位和弦旁边有变音记号。先看看上下两手是否都需要一点宽度；若需要，选首拍任一音，在“共用拍位”先增加 0.5 谱间。再查看整行。如果只有一个力度记号挡住了音，就在“符号位置”单独移这个记号。Ctrl+Z 撤销刚做的一项；“恢复自动”重置当前所选位置的对应属性。

按正常方式保存 MSCZ。导出 PDF 使用这份正式页面的分行、排版和字体。动态乐谱也从所选总谱或分谱的页面取图，画幅与字幕可以在视频面板独立调整。

想请 Codex 帮忙比较时，先选中需要整理的几小节，说明具体问题。例如“保留两个谱表的音和踏板，试一下第 12 小节共用拍位多留 0.5 谱间，让我看整行前后图”。建议出现在“编配建议”。选中该条，点“排版前后图…”，可切换“显示整行”。满意后点“使用这版”，或点“保存排版副本…”留下独立的 MSCZ。Ctrl+Z 撤销刚采用的排版。

## 切换 CFX 后继续写谱

打开使用 CFX 的谱时，谱面先出现。音源准备期间可以选音、作曲，并用内置 SF2 播放。打开“视图 → 音源与效果”可以看准备状态。CFX 准备好后会在停播时接回谱中配置。加载失败时，可保留 SF2 继续编曲，或停播后点“重新载入音源”。

若你希望所有钢琴共用一套音色，在音源面板启用共用钢琴。需要各谱独立预设时，打开相应乐谱并选择使用本谱的音源。同一总谱与它的分谱继续使用当前总谱的音源。

播放中用 Ctrl+S 时，已完成的滚轮力度调整会写进文件。停播后可用普通撤销恢复这次调整。可在另一份副本里重新打开刚保存的文件，核对调整过的音。
