# 多谱性能与原曲操作检查

2026-10-26，0.123.0已安装。

## 已确认的原因

1. 主和弦面板隐藏后，谱面和弦开关继续使分析保持开启。整体关闭现会结束相关任务并清理所属显示；设置继续保存。
2. 修改音符力度会使整谱内容版本变化，旧路径随之重读音符、重算全部和弦。现在核对原生撤销记录：仅包含音符力度保存方式与数值时，继续采用原和弦索引；撤销、改音高及其它操作走对应更新。
3. 谐音资料相同而排版变化时，复用识别结果并重新放置记号。比较同时包含拍号与乐器范围，保留已有人工解释文件的读取方式。
4. 波形拖动原先直接选范围，普通原曲播放也采用当前片段起止。现在定位、选段、播放限制各自清楚控制。
5. 铅笔起笔原先经过重叠音取点，可能先缩小选择。绘制工具现在保留原有选择；拖动工具继续负责单音选取与轮换。

## 连续过程

使用独立生成的钢琴测试谱，打开四份，逐次切换实际标签，铅笔画力度，再用Ctrl滚轮缩放。每轮读回撤销数量、和弦索引及分析次数，并记录进程私有内存。128小节与600小节分别检查。

较早检查已确认整体关闭错误；前期测试中的取点和标签操作不足已修正。最终耗时采用真实标签与Ctrl滚轮的记录。

## 原曲实际操作

使用四秒测试录音，实际点定位与选段，拖波形、开关只播选段、等待片段结束，再关闭限制继续播放。核对实际播放计划的起止时间。勾选谱面按钮，点击播放、再次点击停止，然后隐藏按钮。互停、快捷键、循环、联合播放和文件保存继续回查原流程。
