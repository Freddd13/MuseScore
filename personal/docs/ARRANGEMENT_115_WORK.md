# C2-A：和声上下文与明确音线

当前安装0.114.0；0.115.0正在检查。

## 已查到并修复

- 重复音被当作邻音，休止两侧的音也被当作连续经过音；复调内音会借用另一条线的前后音解释。
- 持续判断只看音符剩余长度，没有按实际和弦范围和另一音的持续时间计算。
- 交叉只比较前后上下互换，漏掉范围开始前已经交叉、经过同音后交叉的情况；隐伏规则会在交叉后误把低音跳跃当成旋律跳进。
- 共享自动解释经区间叠加后被改成手动来源，提示来源和程度随之改变。
- 人工和弦先发布分析再写谱内记录，保存修改后共享结果被标为过期。现在在谱内写入后发布当前结果，联用检查及撤销已核对。
- 剩余插件的公共音乐模块停留在较早版本。现在与内置工具使用相同的当前源码；发布准备同时维护两处。

32份人工指定预期的片段在JS与真实谱窗中核对，涵盖平行／反向／反向进入、增减音程、加倍、交叉、休止、非和弦音和来源。原版本19例符合这些预期，修复后32例符合。面板实际点击、分类筛选、谱旁位置、跨工具更新和撤销一起检查。
