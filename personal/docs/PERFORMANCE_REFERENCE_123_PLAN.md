# 优先修复卡顿与原曲播放操作

2026-10-25。当前安装0.122.0。用户报告多谱、铅笔改力度及和弦工具使用后，缩放和播放越来越卡。本轮插在C3之前；完成下面的修复后，继续C3、C4、D、E、F。

## R1：找出持续变慢的原因

复现过程采用多份独立钢琴测试谱：打开和弦助手及编辑器，用铅笔连续改一段音阶的力度，多次切换乐谱，再缩放、播放、停止和关闭工具。

分别记录未开工具、只开编辑器、只开和弦、两者同开时的耗时、界面响应、内存及分析次数。连续做多轮，核对后面的操作是否变慢。重点检查重复连接、未停止任务、重复全谱读取、谱面标记重排、隐藏窗口和旧谱资料。

先修有实际证据的开销。力度修改、缩放和选择分别判断更新内容；同一轮操作合并刷新。可见内容与音乐分析各自复用已经准备的资料。

## R2：和弦助手能彻底关闭

已查到：当前主窗口隐藏后，只要谱面和弦开关仍开着，就会继续保留标记和分析。

- 菜单／工具栏关闭和弦助手时，结束本工具任务，关闭摘要和详情，清理所属谱面标记、着色和范围手柄。
- 保留个人显示设置。再次打开后恢复这些选择并显示当前谱。
- 单独关闭摘要、详情或谱面记号，继续保留原有的独立控制。
- 检查多谱之间的所属关系；关闭期间改谱、播放和缩放时，和弦工具保持停止。

## R3：普通播放与选段分开

波形工具提供“定位／选段／手形”。普通定位可直接点播放位置，拖动时也能改变位置；只有选段工具或已选端点用于修改范围。

一级播放区放“只播选段”和“循环”两个独立开关：

- 普通播放从当前播放头继续到曲尾。
- “只播选段”开启后，在选定范围内播放。
- 循环按当前播放范围重复。当前范围用简短文字显示。
- 点关联行的“播放片段”明确试听该关联，停止后回到原有播放设置。

既有片段、关联和音轨设置继续读取。换轨后恢复自己的播放头与范围，保留删除、恢复和保存。

## R4：方便在原曲与乐谱之间比较

“原曲／乐谱／一起播放”继续使用明确的播放对象。Ctrl+空格控制原曲，快捷键可设置。

把现有互停设置放到容易找到的播放设置中：播放原曲时停止乐谱、播放乐谱时停止原曲，分别勾选。联合播放按联合会话处理。

增加前后定位与回到片段开头的快捷操作；波形获得焦点时可以用方向键微调，较大步长有明确提示。关联仍按具体音符或休止的起止拍位、多对多对应及反复遍次保存。内部对齐点和时间偏移集中在当前关联旁调整。

## R5：谱面直接播放关联片段

提供“在谱面显示原曲播放按钮”开关。在关联起点附近显示紧凑的播放／停止入口，能辨认音轨和片段。相同位置的多个关联在同一入口选择；隐藏后保留资料。

点击后显示当前播放对象和范围，重复点击可停止；播放器、频谱和谱面共用位置与状态。按钮避开音头，可隐藏和恢复。

## 怎样检查

1. 多谱连续改力度、切换、缩放和播放，记录每轮响应及内存，检查任务和连接数量。
2. 关闭全部和弦功能后，确认标记、颜色和手柄清空，分析停止；重新打开当前谱继续正确显示。
3. 普通点击／拖定位保持原范围；选段工具、端点、只播选段与循环逐项核对实际播放位置。
4. 交叉使用Ctrl+空格、面板空格、普通乐谱播放和联合播放，核对互停、再次播放和位置恢复。
5. 谱面快捷入口播放不同音轨和反复遍次；隐藏、关闭面板、换谱和保存重开后继续检查。
6. 正常大小下看控件的自然宽度、对齐、范围说明和画布空间。原有声音、选音、撤销及保存一起回查。

每完成一批，更新实际原因、修改、图片、测量及发布说明。当前C3等原任务保留在[完整进度](REWORK_PROGRESS.md)。
