# 循环、反复改速与旧谱读取

版本：0.155.0 · Kumo branch / Freddd13。

这次更新改善已有播放与读谱操作。循环返回、反复段中临时改速、最近文件和旧谱文字继续使用原来的入口。

## 循环播放和反复段中改速度

打开要练习或比较的乐谱，在播放面板设置循环起止位置，开启循环后播放。循环起点可以落在长音中间或没有新音的位置。停播后可继续编辑、再次播放；演奏表达和其它工具的试听也沿用这套定位处理。

播放到反复的第二遍时，可以在播放面板调整临时速度。当前位置留在这一遍的同一拍附近，随后按新速度继续。与原曲一起播放时继续使用已有的音频对应。

## 找回最近打开的谱

从“文件”菜单打开最近文件列表。软件记住最近60份，列表最多显示20份尚未打开的文件；关闭一份谱后，它会回到列表前面。

当记住的文件都已经打开时，列表显示“最近文件均已打开”。直接从上方的乐谱标签切换即可。

![所有最近文件均已打开时的菜单提示](images/upstream-recent-155.png)

## 打开新版和旧版文字

正常打开乐谱即可。新版MuseScore写入的多行标题、说明继续按行显示；旧1.x谱子的HTML换行同时保留。导出PDF采用相同的文字排版。

## 分节停顿与GP6

使用分节符并在检视器设置停顿后，关闭“展开反复”仍会保留分节停顿。常规播放与MIDI导出读取相同的分节时间。

通过“文件 → 打开”读取GP6文件。含延长记号和多个声部的文件会检查实际落点；小节数按文件中的完整列表读取。

## 保存和撤销

临时播放速度继续按原来的播放设置使用。修改分节停顿后保存乐谱；读入GP6后可另存为MSCZ继续编辑。谱内修改沿用原有撤销。

安装程序位于`msvc.install_repair_current_x64/bin/MuseScore3Evo.exe`。合入来源及实际检查见[本次检查记录](UPSTREAM_155_CHECKS.md)，发布定位为`personal-v0.155.0`。
