# 使用演奏中的快慢变化

对应个人版本0.97.0 · Kumo branch / Freddd13。

演奏表达可以把 MIDI 或录制中这一句的快慢变化用到乐谱。力度和速度分别使用：想先改力度，可点“使用力度”；想采用快慢变化，再开启“使用速度”。

## 从导入到使用速度

1. 在谱面选中要处理的一句，打开“视图 → 演奏表达”，点“当前选区”。看目标行确认小节、谱表和声部；处理整首时点“全谱”。
2. 点“导入 MIDI”，或点“录制”弹奏。对应完成后，先查看音名、拍位和演奏时间，调整明显错配的音。完整演奏可以用来寻找选中的短段。
3. 开启“使用速度”，在“设置与详情”中调整速度采用比例和“保持这段时长和两端速度”。状态行会写出本次段数、原时长与拟采用时长。
4. 应用范围选择“选中音”“当前选段”或“全部已对应范围”。选几个分开的音时，软件分别计算各音占用的范围，并接回旁边的原速度。速度会影响同一位置的所有声部。
5. 点“谱中效果”和“拟采用效果”比较。按钮会显示当前正在听的一项；“停止试听”结束比较。
6. 点“使用速度”。谱里的速度区显示写入结果，Ctrl+Z撤销本次采用，重做可恢复。

“保持这段时长和两端速度”适合保留乐谱原有的句长，在句子中间加入快慢。关闭后，段长会按采用比例向演奏时长靠近。只选很短的音时，可调整的空间较小；选完整一句更容易比较自然的快慢变化。

在编辑器速度区拖动拟采用曲线后，软件会重新整理相邻速度，保持选定的段长要求。

谱上的固定速度、rit.、a tempo和延长记号继续参与计算。已有记号所在的区间在详情中写明保留原因；其它部分仍可采用。整体传输速度滑块的倍速继续由播放控制。

## 分几次采用

例如先选第1小节的一个音和第2小节的一个音，应用范围选“选中音”，再点“使用速度”。随后框选第3小节，将范围改为“当前选段”，可以继续采用这一小节。前面已经使用的速度保留，各次采用各有一次撤销。

采用后，当前范围已处理的速度从待使用数量中收起。还可以继续处理力度；两者各自记录进度。调整谱中速度后，可重新对应，再查看新的比较结果。

## 录制时有长休止

“录制结束”可选“手动停止”“到时停止”或“弹完选段停止”。最后一种会根据所选音序判断弹到哪里：句中的休止继续等待，末音弹完并松键后自动结束。录完在当前页显示对应音和力度，可直接试听、修正和使用。

## 保存和恢复

- Ctrl+S保存已经采用的力度、速度和力度恢复资料。
- “更多操作 → 保存表达项目”保存原始演奏、人工对应、所选片段和采用进度。重开乐谱后打开这个项目，可以继续处理。
- 一次采用对应一次乐谱撤销。应用前力度的恢复入口继续支持选音、选段和全曲。

分别选音、修改对应与力度操作见[演奏表达](EXPRESSION_096_GUIDE.md)。录制起步见[录完后继续操作](EXPRESSION_080_GUIDE.md)。
