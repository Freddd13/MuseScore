# 试写方案

独立 Arrangement Variants 插件。选谱段，新建组并选择工作区位置。原始基准只读；A及复制方案是完整MSCZ副本，在原生标签页自由编辑。点选方案后“切换并定位”或“从同处试听”；双击同样切换。支持名称修改、多个组、反复出现次数、悬浮及顶部紧凑布局。

默认预滚一小节；入段延音或踏板扩大上下文，界面报告实际范围。停播并等待渲染后切换；段末GUI heartbeat停止和释放。基准不允许插件写回或覆写。副本/布局仍同步，有耗时报告，未实现无缝边播切换。

检查差异按小节分页，比较长度/拍号、段外音乐内容及跨段spanner。段内允许自由编辑；段外变化取消同条件比较。保存当前方案生成新的独立文件，再原子更新版本化工作区清单；保留旧方案文件。其它已打开方案需逐个切换保存；未保存标识针对工作区快照。关闭后打开工作区恢复，文件缺失/摘要变化拒绝加载，需先人工核对文件。

“另存为成果谱”保留整个当前方案，不进行局部合并。不会改用户原谱的路径、dirty或撤销栈。音频和图片、分谱/链接及个人演奏数据使用原生MSCZ保存路径。局部合并、自动重基和同窗口工作区仍后续。
