# 原曲参考 1.0

启用 ReferencePlayer_MS3.qml。需要 Kumo 的可选 kumo_referenceaudio 媒体扩展；缺失只显示功能不可用，不影响插件菜单。默认底部，可拖动停靠或悬浮；本地 WAV/MP3/FLAC、单/双声道。

播放原曲使用独立按钮，不占用原谱空格。速度 50–150% 保调，滚轮放大波形、拖动选 A/B，拖边界微调，毫秒框精调。循环淡入可关闭。音量与速度保存读取。右上项目菜单保存/恢复 JSON，音频是外部引用；文件大小或修改时间变化将关联标成待核查。

选择谱段和音频片段后“关联选区”。定位谱、谱位→原曲及内部锚点采用手动单调对应；同一音频可关联多段。谱面编辑相关范围后关联待核查，不自动改变速度或同步播放。书签从项目菜单查看。关闭/隐藏停止该播放器；原谱播放与编辑保持独立。

三种格式和保调/时间误差/设备支持以 P1 验收报告为准。多声道、M4A、频谱、精确联合运输不在首版。
