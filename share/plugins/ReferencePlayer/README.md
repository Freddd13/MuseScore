# 原曲参考

运行“插件 → Reference Player”，打开或拖入WAV、MP3、FLAC。设置片段开始／结束，开启循环，再调速度慢听。面板有焦点时，空格播放／停止；点击谱面后，空格控制乐谱。

多个文件各自成为音轨，可调音量、静音和独听。选谱段、选音频片段、点“关联”；关联列表可以跳到乐谱、跳到音频或播放片段。同一源片段可关联多个谱段，不同音轨也可关联同一谱段。

播放可选原曲、乐谱或一起播放；联合播放提供开头对齐、跟随乐谱和跟随选定音频三种方式。项目菜单保存素材位置、片段、书签和关联。
