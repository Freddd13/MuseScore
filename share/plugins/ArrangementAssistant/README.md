# 编配检查 ArrangementAssistant 1.0.0

适用于本仓库对应的 MuseScore 3 Evolution Kumo **personal-v0.25.0 及以上**。依赖同级 `HarmonyAssistant/` 的 Harmony.js、Timeline.js、Analysis.js 和 Desk 控件；不要求启动和声助手窗口。

## 使用

1. 插件管理器勾选 `ArrangementAssistant_MS3.qml`，从 **插件 → Arrangement Check** 启动。
2. 默认取选区所在的钢琴声部组；没有选区取当前小节。非连续选择按起止范围检查，面板会说明。可切换为当前钢琴全谱。
3. 首次点击“分析”。问题列表选择后显示依据；停播时“定位”使用原生选择，播放中仅显示缓存，定位请求等待停播。
4. 拖到顶部为摘要；设置中允许摘要与右侧详情同时显示、摘要对齐；支持浮动。列表和依据各自滚动，不随问题长度改变区域高度。
5. “声部／分手”校正自动候选、独立声部及左右手，也可对所选音或范围指定手。“局部和弦”指定本谱范围的解释；“导入和声”读取和声助手 schema 2 JSON。

设置包含调性钢琴／流行、严格对位和爵士预设、分类及单项规则开关、左右手跨度。默认舒适大九度、最大小十度、两端白键允许大十度。导音提示只有用户明确指定主音后启用，不以调号猜主音。

## 边界

- 只读提示，不自动改音、生成指法或往谱面写警告文字；扩展音、经过音、邻音、挂留不会一概判错。
- 分手符号精确附着和有结束点的范围优先；冲突或缺少范围结束点标“待确认”。自动推断的复调 voice 不当成已确认的独立声部。
- 修改后停播约 750 ms 延迟刷新受影响范围及延音／踏板上下文；播放期间和隐藏时取消任务。规则在独立 JS 引擎处理值副本。
- 通用外观和规则参数自动保存。角色、所选范围分手、忽略位置、局部和弦与导入解释只用于当前谱会话，换谱清空，避免误套到其他乐谱；P0 不实现跨插件实时共享纠正。
- 可弹性是个人参数与上下文提示，不保证可弹，也没有伪精确难度分数。复杂装饰、自由节奏和完整指法求解属于后续。

## 验证

`node ArrangementAssistant/tests/test-rules.cjs`：27 项音乐规则边界。

`python ArrangementAssistant/tests/test_panel.py`：独立 QML 夹具的侧栏／顶部／双面板／设置及缓存交互。生产性能应看宿主 `mtest/mscore/p0native` 的真实 JS worker 和完整分页测试；夹具的 GUI 回退不是生产后台引擎。

完整宿主实现、构建入口和导出保护见 [P0 说明](../P0/README.md)。
