# 编配检查

在谱面选中一段，运行“插件 → Arrangement Check”，选择风格后点“分析”。列表会显示和声、对位和钢琴演奏中的疑点。点一条看依据，点“定位”跳到相关音。

“声部／分手”可把自动建议改成自己的旋律、低音、内声部和左右手；分解和弦也可在这里确认为独立声部。个人跨度沿用你的九度／十度设置。

例如“左手先松开C2，再弹下一组音”，表示踏板会继续保持C2的声音，手可以移到下一组音。详情写出原先按键数量、松手后数量和手位移动。

想在谱上看提示，打开设置并勾选“在谱面提示当前问题”。点列表中的问题，谱面出现“松手”“手位”“对位”或“和声”标记；点标记可回到详情。这个开关也用于隐藏标记。

修改谱子后，停播约750毫秒更新相关范围。播放期间可以查看已算好的结果。通用设置自动保存；角色、局部和弦与忽略位置随当前谱会话使用。

当前插件1.2.0，与个人软件0.46配套。依赖同级HarmonyAssistant目录中的算法和控件。
