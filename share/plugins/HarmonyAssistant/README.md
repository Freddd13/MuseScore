# 和弦助手

配套版本：插件1.10.0，个人软件0.50.0。

在插件管理器启用 HarmonyAssistant_MS3.qml，再运行“插件 → Harmony Assistant”。打开谱子后，状态依次显示读取、分析和已更新。选音或播放时查看当前位置的和弦、带转位的级数和音程功能。

打开“谱面上方显示和弦／级数”，可在和弦变化位置看到记号。暂停后双击一个记号，会打开这段和弦的修改区。选择“在谱面和面板显示范围手柄”，拖两端改变和弦范围；拖记号主体调整显示位置。点“撤销修正”可退回一步。

顶部摘要和右侧详情可以一起打开，分别控制显示。顶部“更多 → 摘要外观与调性”可调字号、级数大小、间距、上下或左右排列，以及主音与大小调。详细设置按用途分组折叠，点分组标题展开。

“记号列表”用于逐段定位和修改。JSON保存分析、人工范围与手动位置，CSV方便查看表格。配色和个人显示设置自动保存。
