# 和弦助手

配套版本：插件1.8.0，个人软件0.44.0。

在插件管理器启用 HarmonyAssistant_MS3.qml，然后运行“插件 → Harmony Assistant”。打开谱子后开始读取；点音或播放可看当前和弦。开启“谱面上方显示和弦／级数”可看和弦变化的位置。

双面板同时提供顶部摘要和右侧详情；摘要的位置、配色、字体及和弦／级数排列可在设置中调整。转位会同时显示在和弦名称和级数中。状态会说明正在读取、正在分析或已更新。

记号列表用于定位和修改识别点、范围；JSON用于保存和恢复分析，CSV用于查看表格。配色和个人显示设置自动记住。
