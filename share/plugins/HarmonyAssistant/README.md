# 和弦助手

配套个人软件：0.77.0 · Kumo branch / Freddd13。

从“视图 → 和弦助手”打开。当前位置会显示和弦、级数、转位和分析状态；谱面记号在“谱面显示与着色”中开启。

“修改和弦与范围”位于当前和弦下方。暂停后双击谱面记号也能进入；选择根音、种类和低音，点“指定和弦”。两端手柄改音乐范围，拖文字改显示位置，Ctrl+Z撤销。人工修改随乐谱保存。

“设置 → 外观、功能色与文字”把顶部摘要、右侧详情和谱面记号分开设置。摘要与详情可分别选择一行／两行、显示内容、字号、间距、字体和颜色；长设置可以折叠。个人外观自动保存。

修改音高后人工和弦继续保留。增删小节、改变拍号或谱表后，按提示核对范围。
