# 演奏表达

选中谱段，打开“视图 → 演奏表达”。主要操作在演奏编辑器内：导入演奏 MIDI，或点“录制”用 MIDI 键盘弹一遍。弹完停止录制，即可查看自动对应和力度预览。全曲 MIDI 会先寻找选中段，再逐音对应。原插件入口打开同一个工具。

在原来的力度／速度区域查看前后效果。同音对比采用两根并列实心柱：中性色是谱中效果，强调色是拟采用效果；拖强调色柱可以继续调整。要检查两个音怎样对应，打开“更多操作 → 在编辑器调整对应”。

新材料默认采用 100% 演奏力度，可以调节“采用演奏力度”的比例。用“谱中效果／拟采用效果”比较，播放时切换接着当前拍位听。选择选中音、当前选段或全部已对应范围，再点“使用力度”。按钮上的数字是这次更新的音符数量。Ctrl+Z 撤销整次采用。

首次使用力度时，软件会把这些音原来的力度随乐谱保存。“更多 → 恢复应用前力度”可以在重开 MSCZ 后按音、选段或全曲恢复。已经使用的音从待处理列表收起；更多菜单可以重新显示。

重复段出现几个合理位置时，选择带时间的候选。点“漏弹／多弹／需核对”查看并定位具体位置。需要修改配对时，打开对应轨，选择谱面音和演奏音后连接；“固定这一处对应”让后续音从这里继续对齐。

“设置与详情”提供音序敲击、演奏对象和录制设置；“使用速度”处理 rubato。“更多操作”保存或恢复项目与力度。勾选“保留手动调整”后，先前逐音设过的力度会保留下来。
