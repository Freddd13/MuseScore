# 演奏表达

选中谱段，运行“插件 → Performance Expression”，导入演奏MIDI。全曲MIDI会先寻找选中段，再逐音对应。

点“编辑器对比”查看原力度和演奏力度，调整应用强度，用“试听原来／试听新力度”比较。点“使用力度”将结果用于谱子；一次Ctrl+Z可恢复整次修改。“保留手动调整”可保留先前逐音设置的值。

重复段有多个合理位置时，选择带时间的候选。“更多设置”提供音序敲击、对象和人工对应。“使用速度”单独处理rubato。项目菜单保存原始MIDI、对应和参数。
