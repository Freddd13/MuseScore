# 演奏表达

选中谱段，运行“插件 → Performance Expression”，导入演奏MIDI，或点“录制”用 MIDI 键盘弹一遍。弹完点“停止录制”，即可查看自动对应和力度预览。全曲MIDI会先寻找选中段，再逐音对应。

点“编辑器对比”，在原来的力度／速度区域查看前后效果。空心框是谱中效果，实心条是拟采用效果；拖实心条可以继续调整。要检查两个音怎样对应，打开“更多 → 在编辑器调整对应”。

调好力度强度后，用“谱中效果／拟采用效果”比较。播放时切换会接着当前拍位听，谱子和编辑器留在原处。选择“使用范围”：选中音、当前选段或全部已对应范围，再点“使用力度”。按钮上的数字就是这次将更新的音符数量。一次 Ctrl+Z 可撤销整次应用。

首次使用力度时，软件会把这些音原来的力度随乐谱保存。“更多 → 恢复应用前力度”可以在重开 MSCZ 后按音、选段或全曲恢复。已经使用的音从待处理列表收起；更多菜单可以重新显示。

重复段出现几个合理位置时，选择带时间的候选。点“漏弹／多弹／需核对”查看并定位具体位置。需要修改配对时，打开对应轨，选择谱面音和演奏音后连接；“固定这一处对应”让后续音从这里继续对齐。

“设置”提供音序敲击、演奏对象和录制设置；“使用速度”单独处理 rubato。项目菜单保存原始 MIDI、对应和参数。勾选“保留手动调整”后，先前逐音设过的力度会保留下来。
