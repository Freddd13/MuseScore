# 演奏表达

选中谱段，运行“插件 → Performance Expression”，导入演奏MIDI，或点“录制”用 MIDI 键盘弹一遍。弹完点“停止录制”，即可查看自动对应和力度预览。全曲MIDI会先寻找选中段，再逐音对应。

配合个人版0.47，点“编辑器对比”会直接展开对应轨。上排是谱面起音，下排是演奏起音；指向点可看音名与数值。同一时刻的音分开展示。

查看原力度和演奏力度，调整应用强度，用“试听原来／试听新力度”比较。插件和编辑器对应轨中都有“使用力度”，可将结果用于谱子；一次Ctrl+Z可恢复整次修改。“保留手动调整”可保留先前逐音设置的值。

重复段有多个合理位置时，选择带时间的候选。“更多设置”提供音序敲击、对象和人工对应。“使用速度”单独处理rubato。项目菜单保存原始MIDI、对应和参数。
