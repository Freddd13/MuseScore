# 演奏表达

独立插件 Performance Expression。选择谱段、导入演奏MIDI，指定按谱／任意音高敲击及旋律／voice／全声部，再自动对齐。先检查待确认／漏弹／多弹；连接可重新选择，取消对应，设／移除锚点。重复节奏和错音不自动接受；人工对应保存在工作区，原始MIDI按SHA256复制，后续读取验证原始文件未变化。

纯值Alignment.js在ScoreObserver隔离QJSEngine worker运行；分批performanceRange保持P0 analysisRange接口。自动读取停止播放后执行，隐藏／改谱取消，缓存标记过期。读取PPQ／SMPTE、tempo map、逐音力度、轨道、控制和meta值，不将MIDI打开成新谱。

力度／rubato分别启用与调强度（默认50%），设备中心／斜率校准；推算伴奏仅显式开启，来源标明。生成候选后查看差异／保护及原／候选曲线；受保护行点击可明确解锁该音。保存工作区后使用原／候选完整谱副本试听，再返回原谱应用。

Rubato默认保留段长和边界，速度对所有声部生效，有限隐藏点写回；已有速度文字／曲线保护，无法满足段长拒绝应用。停止播放和渲染后完整旧值预检、一次Undo，读回异常回滚。原始MIDI／人工对应保留。试听上下文含入段延音及踏板，段末停止采用GUI heartbeat；无驱动可查看副本并返回。

Tap下拉可写指定谱面起音；已有速度必须明确选中，新建可见，保留拍单位和说明。相对速度／曲线交原演奏编辑器。节奏重新记谱／实时捕获不包含。合成真值测试与真实演奏素材验收分别记录，不能用前者代替后者。
